# 04 · 书籍解析规范

> 四种格式，一套出口。所有解析器最终产出同一个 `Book` 结构（见 `03`）。
> **渲染层永远不知道这本书原来是什么格式。**

---

## 1. 总体流程

```
文件路径
   │
   ├─ 扩展名/MIME 嗅探 ──► 选解析器
   │                        │
   │                        ├─ txt.ts   ┐
   │                        ├─ epub.ts  │
   │                        ├─ mobi.ts  ├─► 统一 HTML/段落流 ──► blocks ──► Book
   │                        └─ pdf.ts   ┘
   │
   ├─ 写入 data/books/{id}/book.json（缓存）
   └─ 返回 Book
```

**缓存键**：`bookId + PARSE_VERSION + 文件 mtime + 文件大小`。
任一变化 → 重新解析。`PARSE_VERSION` 在 `parsers/index.ts` 顶部定义，**解析逻辑改动必须 +1**。

---

## 2. 归并策略（同书多格式）

扫描书库时，同一个文件夹下出现多个电子书文件 → 视为**同一本书的不同版本**。

```
候选文件                      质量分
  *.epub        ────────────►  100   （排版最佳、体积小、有目录）
  *.mobi / *.azw3 ───────────►   90   （排版好，需解包）
  *.pdf         ────────────►   70   （版式固定，可能扫描版无文本层）
  *.txt         ────────────►   60   （纯文本，无排版信息）
```

规则：
1. 选**质量分最高**者为默认 `format`
2. 用户在书籍详情里可以手动切换格式（`variants` 全部保留）
3. 切换格式**不重置进度**——按章节标题模糊匹配迁移位置；匹配不到则按全书百分比迁移
4. 书名以最高质量格式的元数据为准，缺失时回落文件名（清洗 `[xxx.com]`、`_ISBN` 等噪声）

## 3. TXT 解析

### 3.1 编码检测

```ts
顺序：BOM → chardet 探测 → 尝试 UTF-8 → 失败则 GB18030 → 最后 latin1 兜底
中文书绝大多数是 UTF-8 或 GBK/GB18030。
```

### 3.2 章节切分（两级正则）

```ts
// 一级：明确的章标题（独立成行，长度 < 40 字）
/^\s*(第[0-9零一二三四五六七八九十百千]+[章节卷篇回]|序[章言]?|前言|引言|楔子|后记|尾声|终章|附录|致谢)\s*[\s:：、.．\-—]*(.{0,30})\s*$/

// 二级：目录区识别 —— 连续出现 ≥3 行同类标题且行间无正文，判定为目录，跳过
```

**本书实测**（`负动产时代`）：前 637 行是「内容简介 + 目录重复区」，正文从第 638 行的 `第1章` 开始。
处理方式：

```
1. 先按一级正则找出所有候选标题行（位置数组 hits）
2. 若在前 25% 区域内存在 ≥3 个连续候选，且它们之间的间距 < 6 行
   → 判定为目录区，把这些标题"降权"
3. 真正的章节起点 = 目录区之后第一次出现的同级标题
4. 兜底：若一条标题都没找到 → 按每 3000 字切一章，标题为"第 N 节"
```

### 3.3 段落切分

```
· 以空行（连续 ≥1 个换行）为段落分隔
· 单行内若超过 200 字且无标点换行 → 仍视为一段
· 去掉行首全角空格（交由 CSS 缩进）
· 合并软换行：一行结尾不是句末标点且下一行不以缩进开头 → 视为同段
· 过滤纯空白、纯符号行
· 图片标记 `[插图]`、`[图片]` 保留为 img 占位（无图源时渲染为极淡的分隔）
```

### 3.4 标题识别（章内）

```
长度 ≤ 20 字 且 不含句号 且 独立成段
  → 且 前后有大量空行
  → 判为 h2（章内小标题）
```

## 4. EPUB 解析

```
1. 用 jszip 打开
2. 读 META-INF/container.xml → 得到 OPF 路径
3. 解析 OPF：
     · metadata → title / creator / publisher / date
     · manifest → id → href / media-type
     · spine    → 阅读顺序（itemref 顺序 = 章节顺序）
4. 目录（三选一，按优先级）：
     a. EPUB3 nav.xhtml（properties="nav"）
     b. toc.ncx → navMap 树（EPUB2）  ← 本书用这个，3 层嵌套
     c. 无目录 → 用 spine 每篇的 <title> 或首個 h1-h3
5. 逐篇读 xhtml → html.ts → blocks
6. 封面：
     · OPF meta[name=cover] → manifest item
     · 或 guide/reference[type=cover]
     · 或第一张图
     → 抽到 data/books/{id}/cover.jpg（缩放到宽 ≤ 480px，JPEG 质量 82）
7. 内嵌字体：忽略（统一使用系统字体，保证四格式观感一致）
```

### 4.1 目录树保真

本书 `toc.ncx` 有 3 层（章 → 节 → 小节），共 142 条。转换规则：

| NCX 深度 | 映射 `level` |
|---|---|
| 1 | 1 |
| 2 | 2 |
| 3 | 3 |
| 4+ | 4（最多 6） |

- 没有 `<content src>` 的中间分组节点**不能丢**：用第一个带链接的后代作为落点，但显示层级仍保留原深度。
- 同一 block 上的多个目录项**不合并**；正文切分只按唯一锚点，目录保留全部原生节点。
- 目录树完全按原生 `level` 建父子关系，不再用 `blockId` 猜节点类型。

同时**章节切分以 spine 为准**（一本书可能一篇含多章），而 TOC 只作为跳转锚点：
- TOC 的 `src` 形如 `text/part0005.html#Point28`
- → 找到对应 spine 索引 → 得 `chapterId`
- → 在原文中查找 `id="Point28"` 的元素，定位到它所在的 block 索引 → `blockId`
- 查找前面最近的 block 时，切片必须包含锚点所在的标签（`slice(0, idx)`，不是 `slice(0, lt)`），否则会退回前一个标题，整条目录错位一节。

若找不到锚点，退化为章首。

## 5. MOBI 解析

```
1. 用 `mobi` 包解包 → 得到 HTML 字符串 + 目录（部分文件有）
2. HTML 走 html.ts → blocks
3. 目录缺失时，用 h1/h2/h3 结构反推
4. 封面：mobi 包的 extractCover
```

**已知限制**：部分加密（DRM）MOBI 无法解析 → 解析失败时**自动回落到同书的其它格式**（本项目书有 EPUB，会直接回落），并提示用户「MOBI 受保护，已改用 EPUB 打开」。

## 6. PDF 解析

PDF 与其它三种本质不同：它没有"语义段落"，只有"页面上的字形位置"。

### 6.1 双模式

| 模式 | 触发 | 行为 |
|---|---|---|
| **文本流模式**（优先） | pdfjs `getTextContent()` 抽取到足够文本（每页 > 100 字，且全书文本层覆盖率 > 80%） | 按行合并成段，按 outline 切章，进入正常流式阅读 |
| **页面模式**（兜底） | 扫描版 / 无文本层 | `PdfView` 用 canvas 逐页渲染 + pdfjs 文本层做选择 |

### 6.2 文本流模式的行 → 段合并

```
1. 取每页 textContent.items（含 transform 坐标）
2. 按 y 坐标聚类成行（容差 3px）
3. 行内按 x 排序，拼接（中文不加空格，英文词间加空格）
4. 行 → 段：
     · 若行尾以句末标点结尾，且下一行首字有缩进（x 偏移 > 2 字符宽）→ 新段
     · 若行尾无标点 → 续行合并
     · 垂直间距 > 1.6 倍行高 → 强制分段
5. 丢弃页眉页脚：
     · 出现在页面顶部/底部 8% 区域
     · 且在多页重复出现（归一化后比对）
     · 且长度 < 30 字
6. 丢弃纯页码行（/^\s*[-—·]?\s*\d{1,4}\s*[-—·]?\s*$/）
```

### 6.3 PDF 的进度与标记

- 章节来自 outline；无 outline 时按每 20 页一章（标题「第 N–M 页」）
- `blockId` 规则与其它格式一致，`text` 用于搜索
- 页面模式下，标记退化为**页级**：`mark.blockId = 'c{chapter}#page{n}'`，渲染为页面左上角书签角标

## 7. HTML → blocks（EPUB/MOBI 共用，`html.ts`）

### 7.1 消毒白名单

```
允许标签：p h1 h2 h3 h4 h5 h6 blockquote em strong i b u s br img figure
          figcaption ul ol li table thead tbody tr td th hr span div sup sub a
移除：script style iframe object embed form input link meta
属性白名单：img[src|alt] a[href] td[colspan|rowspan] th[colspan|rowspan] 及 id/class（仅解析用，不输出）
所有 on* 属性一律删除
```

### 7.2 映射规则

| HTML | BlockType |
|---|---|
| `p` | `p` |
| `h1`–`h4` | `h1`–`h4`（h5/h6 降为 h4） |
| `blockquote` | `quote` |
| `figure > img` | `img`（figcaption 单独成 `caption` block） |
| `img`（独立） | `img` |
| `ul/ol` | `list`（`items` 存每项文本） |
| `hr` | `hr` |
| 裸文本（div 直接包文字） | `p` |

### 7.3 `html` 字段保留策略

为了让 `em`（着重号）、`strong`、`br`、`a` 在阅读时保留，`block.html` 存**精简后的内联 HTML**：

```
只保留：<em> <strong> <br> <a href> <sup> <sub> <ruby> <rt>
其余标签剥离但保留文字
长度上限 8000 字符，超出则退化为纯 text
```

### 7.4 图片

```
· 解析时把图片写入 data/books/{id}/assets/{hash}.{ext}
· block.src = `moqi-asset://{bookId}/{hash}.jpg`
· 主进程注册 protocol.handle('moqi-asset') 读取
· 单图 > 4MB → 跳过（记录日志），避免内存爆炸
· 宽 > 1400px → 用 sharp 缩放（若未装 sharp 则原样，靠 CSS 限制）
```

## 8. 解析质量自检（每个解析器都必须满足）

| 检查项 | 标准 |
|---|---|
| 章节数 | ≥ 1 且 ≤ 2000 |
| 每章 block 数 | 平均 ≥ 3（过少说明切分失败） |
| 总字数 | 与文件大小估算偏差 < 60% |
| `blockId` 唯一性 | 全量校验，重复即报错 |
| 空 block | 自动剔除 |
| 中文占比 | TXT/EPUB/MOBI > 30%（否则可能是乱码） |

失败时：

```
1. 记录 warning 到日志
2. 尝试降级策略（如 TXT 切分失败 → 固定 3000 字一章）
3. 仍失败 → 返回带错误标记的 Book，界面显示「这本书解析不完整，已尽力呈现」
```
