# 05 · 阅读引擎与定位

> 本项目的技术核心。**位置系统一旦出错，续读、标记、笔记全部失效。**
> 三个子系统：① 锚点 ② 进度 ③ 标记与续读。

---

## 1. 锚点系统

### 1.1 三层坐标

```
书 ─┬─ 章 (chapterId = 'c0'...'cN')
    │
    └─ 段 (blockId = `${chapterId}#${index}`)
          │
          └─ 字 (字符偏移 start/end，用于笔记)
```

任何"用户所在的位置"都可以用 `(chapterId, blockId, delta)` 表达，其中 `delta` 是段落顶部相对视口顶部的像素偏移（≤ 0）。

### 1.2 为什么不用 scrollTop 百分比

```
滚动百分比的问题：
  · 改变字号 → 全书高度变化 → 同一个百分比指向完全不同的文字
  · 改变窗口宽度 → 同上
  · 改变版心宽度 → 同上

blockId + delta 的好处：
  · 与排版无关。换字号、换主题、换窗口大小，位置永远精确到同一段同一行
```

**这是"读到哪里"能可靠工作的根本原因。**

## 2. 进度计算

### 2.1 按字数加权（不是按章节数）

```
全书总字数 T = Σ chapter.charCount
当前进度 = (Σ 之前章节字数 + 当前章内已读字数) / T

章内已读字数 ≈ 当前视口顶部所在 block 之前的字数 + 该 block 内的估算偏移
```

实现：

```ts
function computeRatio(book: Book, chapterIdx: number, blockIdx: number): number {
  const before = book.chapters.slice(0, chapterIdx)
    .reduce((s, c) => s + c.charCount, 0);
  const inChapter = book.chapters[chapterIdx].blocks
    .slice(0, blockIdx)
    .reduce((s, b) => s + b.text.length, 0);
  return (before + inChapter) / book.meta.totalChars;
}
```

**每章渲染时预计算 `blockOffsets: number[]`（累加字数），滚动时二分查找当前 block，O(log n)。**

### 2.2 视口顶部 block 的判定

```
1. 滚动事件（passive + rAF 节流）
2. 取所有 block 元素的 offsetTop 快照（章节挂载时算一次，缓存在 ref 里）
3. 二分查找 offsetTop ≤ scrollTop 的最后一个 block = 视口顶部 block
4. delta = el.offsetTop - scrollTop
```

**性能**：1200 个 block 的 offsetTop 只在挂载/尺寸变化时重算一次（ResizeObserver），滚动时只做二分，零布局抖动。

### 2.3 分页模式的定位

```
布局
  · 页容器：宽 = 页区宽 W，高 = 页区高 H，overflow: hidden
  · 正文容器：column-width = W，column-gap: 0，column-fill: auto，height: 100%
    → 每向右溢出的一列 = 一页；换算关系是精确的整数倍
  · 每个 block 宽度 = min(measure × fontSize, W − 96px)，margin-inline: auto
  · 只有 level === 1 的章 break-before: column

页码
  total = max(1, round(flow.scrollWidth / W))
  page  = round(clip.scrollLeft / W)
  跳页：clip.scrollLeft = page × W（瞬时定位；W 用 getBoundingClientRect 的
        小数宽度，绝不能用 clientWidth 取整，否则翻到后面会累计错位）

当前页锚点
  1. 优先取“从本页开始”的第一个 block —— 翻页 / 切模式 / 换字号后都能回到同一页
  2. 若整页都是一段的续文（本页没有任何 block 起点），用 caretRangeFromPoint
     取页首那一行所属的续段
  3. 都失败 → 按列位置扫描，取起始页 ≤ 当前页的最后一个 block
  4. 用 block 的 chapterId + id + 字数比例更新 progress

恢复顺序（打开书 / 切回分页）
  1. progress.blockId 在书里存在 → 定位到该 block 起始页
  2. 否则 progress.pageIndex 有效 → 定位到该页
  3. 否则 progress.ratio → 最近章节的起始页
  4. 都没有 → 第一页

重排（换字号 / 改版心 / 拉窗口）
  1. 先读当前页顶部锚点 blockId
  2. 等字体与图片布局稳定，重设 column-width，重新量 total
  3. 回到该 blockId 所在页；找不到则按原页码比例
  4. 保存 pageIndex，但**不以页码为主锚点**——换字号后页码会变
```

> `blockId` 仍是唯一可靠的主锚点；`pageIndex` 只用于"这一页恰好没有可定位段落"时的兜底。两者同时写入 `Progress`，见 `03`。

## 3. 续读（自动位置）

### 3.1 写入

```
滚动停止 400ms 后 → 保存 { chapterId, blockId, delta, ratio }
另外每 15 秒强制保存一次（防止用户一直滚不停）
窗口关闭 / 切书 / 失焦 > 5s → 立即保存
```

### 3.2 恢复（打开书时）

```
顺序：
1. 读 progress
2. 若无 → 从第一章第一段开始（ratio 0）
3. 若有 → 找到 chapterId 对应章 → 挂载 → requestAnimationFrame 后
         scrollTop = el.offsetTop - delta
4. 若 chapterId 已失效（书重新解析过）→ 用 mark.excerpt 在全文模糊搜索
   → 找到则定位 → 找不到则按 ratio 定位到最接近的章节
```

### 3.3 恢复时的视觉处理

```
· 不做"滚动动画"，直接定位（滚动动画会让用户等）
· 定位完成后，被定位的那一段做一次极轻的"呼吸"提示：
  background 从 --accent-soft 淡出到透明，600ms
· 顶部浮出 2 秒提示：「已回到上次读到的地方 · 第 3 章」
```

### 3.4 从工作台打开指定笔记

```
· 工作台笔记带 { bookId, chapterId, blockId }；
· App 先打开对应书，并把 OpenTarget 传给 Reader；
· Reader 在书 ready 后等一帧（90ms）再 jumpTo(chapterId, blockId, breathe=true)；
· 同一个 target key 只执行一次，避免重排/翻页时反复跳；
· 返回工作台时保留原来的分区（笔记/分析/足迹），不重置到总览。
```

## 4. "读到此处"标记 ★

### 4.1 交互定义

| 动作 | 结果 |
|---|---|
| 单击任意段落 | 该段成为"读到此处"标记；旧标记取消 |
| 再次单击已标记段落 | 取消标记（进度不受影响） |
| 顶部「回到标记」按钮 | 平滑滚动到标记段落，居中显示 |
| 打开书时 | 自动定位到 `progress`（最新位置），**不强制跳到标记** |
| 若 最新位置 == 标记位置 | 不显示「回到标记」按钮 |

> 这套规则同时满足用户的两个要求：
> ① "点一下就标记，下次从这里读" ② "如果往后翻了，就从最新的开始" ③ "有个按钮可以跳回上次记录的地方"。

### 4.2 视觉规格

见 `06-UI设计规范 §7.3`。要点复述：

```
· 左侧 3px 茶褐竖线（--accent），距文字 18px，圆角 2px
· 竖线顶端一个 12×16 实心书签图标
· 段落背景 --accent-soft，左右各外扩 16px，圆角 6px
· 段落文字颜色不变（保证可读）
· 出现：竖线 scaleY(0→1) 200ms + 背景淡入 240ms
```

### 4.3 与进度共存

```
progress.mark    —— 手动标记（用户意图）
progress.blockId —— 自动最新位置（系统记录）

两者独立存储。用户点段落 → 同时更新两者。
用户继续往下滚 → 只更新 progress.blockId，mark 保持不动。
```

### 4.4 点击与选择的冲突处理（关键细节）

```
点击段落时，必须先判断用户是不是在"选字"：

· 若 mousedown 到 mouseup 之间产生了非空选区 → 视为划选，不触发标记
· 若连续点击两次（双击选词）→ 不触发标记
· 若点击的是段落内的链接 / 高亮 / 笔记圆点 → 不触发标记
· 其余情况（单击空白处、单击文字但未拖动）→ 触发标记
· 触屏/触控板轻点同样适用

阈值：拖动距离 < 4px 且 时间 < 300ms 才算"点击"
```

## 5. 选区 → TextRange

### 5.1 用户选中后

```
Selection API 得到 anchorNode / focusNode / 各自的 offset
   ↓
向上找最近的 [data-block-id] 元素
   ↓
用 Range 计算选中部分在该 block.text 内的字符偏移
```

### 5.2 单个 block 内

```ts
function rangeInBlock(blockEl: HTMLElement, range: Range): { start, end } {
  const pre = document.createRange();
  pre.selectNodeContents(blockEl);
  pre.setEnd(range.startContainer, range.startOffset);
  const start = pre.toString().length;
  return { start, end: start + range.toString().length };
}
```

### 5.3 跨 block

```
1. 收集 Range 覆盖的所有 [data-block-id] 元素（按文档顺序）
2. 第一个：start = rangeInBlock(首元素).start，end = 该块文本长度
3. 中间块：start = 0，end = 全长
4. 最后一个：start = 0，end = rangeInBlock(末元素).end
5. 过滤掉 end - start <= 0 的空 range
6. 若总共选中的可见字符 < 1 → 不创建笔记
```

### 5.4 选区工具条

```
位置：选区上方 8px 居中；若上方空间不足 → 下方 8px
内容：[● ● ● ●]  |  写想法  |  复制
动效：fade + translateY(4px→0)，150ms
失焦（点别处）→ 关闭
按 Esc → 关闭
```

## 6. 高亮渲染算法（Paragraph 组件核心）

### 6.1 问题

一个段落可能同时含有：
- 内联格式（`<em>` 着重号、`<strong>`、`<br>`）
- 多个高亮（不同颜色）
- 当前是否被标记

不能简单地 `dangerouslySetInnerHTML` + 事后加 `<mark>`（DOM 操作易错、React 会覆盖）。

### 6.2 解法：token 化 + 区间切分

```
Step 1  把 block.html 解析成扁平 token：
        [{ text: '他说', tags: ['em'] }, { text: '：好', tags: [] }, ...]
        同时累加得到每个 token 在 block.text 中的 [start, end)

Step 2  收集该 block 上所有笔记的 ranges（来自 notes.json）

Step 3  用所有边界点（token 边界 ∪ range 边界）切分出最小片段

Step 4  每个片段：{ text, tags, noteIds }

Step 5  渲染：
        <span class={tags.includes('em') ? 'em' : ''} style={{'--hl': color}}>
          {text}
        </span>
        若有 noteId → 包一层 <mark class="hl" data-note-id="...">
```

复杂度 O(n)，n = 该段字符数。单段最多几千字，无性能问题。

### 6.3 跨段落高亮的断点处理

```
· 同一 noteId 在多个 block 上各有一段 range
· 每段独立渲染自己的 mark
· 视觉上用圆角区分：段首 range 左侧圆角、段尾 range 右侧圆角
  （首尾判定：该 range 是否是该 note 的 ranges[0] / ranges[last]）
```

### 6.4 高亮 + 标记叠加

```
标记作用于整段（外层容器），高亮作用于文字（内层 span）。
互不干扰：外层加背景与竖线，内层加文字背景。
标记背景是 --accent-soft（极淡），高亮背景更饱和，叠加后仍然可读。
```

## 7. 计时子系统

### 7.1 计时规则

```
启动：阅读页挂载 + 窗口可见 + 窗口聚焦，start(bookId, bookTitle)
暂停：document.hidden 或 window blur → 自动暂停（manual=false）
      用户点暂停 → 手动暂停（manual=true）；失焦/回到窗口不改变手动暂停
      恢复可见/聚焦 → 仅当不是手动暂停时继续
节拍：setInterval 1000ms，累加 activeSeconds；单次 delta 上限 2s
落盘：每 30 秒把本次增量发给主进程；暂停/离开阅读页时立即 flush
重置：只清本次 activeSeconds，重新计时；今日累计保留
退出：stop() flush 后清空本次，回到阅读页重新从 0 开始
```

### 7.2 防挂机

```
单次 tick 距离上次活动超过 3 小时 → 不累加（不写入本次/今日）
任何输入事件 → 重新开始累加
```

### 7.3 展示

```
底栏：本次实时 mm:ss（tabular-nums）+ 今天 X + 暂停/继续
导航栏：本次 28px 大时钟 + 今天/本书今日 + 暂停 + 重置本次
数据面板：实时时钟 + 今日小结 + 2×2 指标 + 按书明细 + 7 天
设置里可完全关闭底栏计时显示
```

### 7.3.1 今日与本书今日

```
今日总时长 = getStats(7).today.seconds + 本次 activeSeconds
本书今日 = 同一天 sessions 中 bookId 相同或书名相同的秒数 + 本次 activeSeconds
        （同名历史书按书名合并，避免书库 id 变化后出现两行）
刷新：start / flush / pause / resume / reset 后重新拉取；
      异步回填用 generation 防止旧请求覆盖新状态
```

### 7.4 主进程聚合

```
session:add({ bookId, bookTitle, seconds, date })
  → 找到 sessions.json 中"同一天 + 同一本书"的最后一条
    · 存在且距结束 < 10 分钟 → 合并（累加 seconds，更新 endedAt）
    · 否则 → 新建一条
  → 每 30 天清理一次 90 天前的原始 session，聚合进 daily 汇总
```

## 8. 搜索

**在渲染进程执行**（`SearchPanel` 内），因为 `Book` 打开后已完整驻留内存，走 IPC 反而是多余开销。

```
中文不分词，直接 indexOf（大小写不敏感，输入防抖 260ms）
返回：{ chapterId, chapterTitle, blockId, offset, before, match, after }
上下文：命中前后各 22 / 34 字
上限：200 条（超出即停，避免长书卡顿）
排序：按书中顺序
结果按章节分组，点击跳转并做 2 次呼吸高亮
```

实测：9.9 万字的书，单次搜索 < 15ms，不卡 UI。

## 9. 性能护栏

| 指标 | 阈值 | 超限动作 |
|---|---|---|
| 总 block 数 | 6000 | 超过 → 只渲染当前章 ±2 章，顶部出现上/下一章按钮 |
| 单章 block 数 | 400 | 超过 → 该章内部分批挂载（每 100 段一批） |
| 单 block 字符数 | 8000 | 超过 → 强制按 2000 字切分为多个 block |
| 高亮数/段 | 30 | 超过 → 用纯色块渲染（不逐 token 切分），保证流畅 |
| 内存 | 350MB | 切书时释放上一本 Book，清空 offset 缓存 |

## 10. 边界情况清单（实现时必须逐条处理）

- [ ] 用户在第一章第一段，向上滚 → 不越界
- [ ] 用户在最后一章最后一段，向下滚 → 到底提示（极淡）
- [ ] 标记段落被删除（换格式后）→ 用 excerpt 模糊找，找不到则提示「原位置已不存在」
- [ ] 笔记 range 越界（block 变短）→ clamp 到 [0, text.length]
- [ ] 同段落被多个笔记覆盖 → 正确分层
- [ ] 窗口从 1280 拉宽到 1920 → 进度不变（blockId 不变），delta 重算
- [ ] 字号从 19 调到 30 → 保持同一段落可见（重新定位到当前 blockId）
- [ ] 切换主题 → 不重排（只改颜色变量），位置不变
- [ ] 打开书时书文件被删除 → 提示并回到书架
- [ ] 快速连点两次"下一章" → 防抖，最终落点正确
- [ ] 输入法组合输入中（写笔记）→ 不触发快捷键
