## 2. 依赖方向（必须单向）

```
src/pages  ──►  src/components  ──►  src/store  ──►  src/lib  ──►  src/types
     │                                                              ▲
     └──────────────────── src/lib/ipc ────────────────────────────┘
                                    │
                                    ▼
                          electron/preload.ts
                                    │
                                    ▼
                          electron/ipc ──► electron/parsers ──► electron/store
```

**禁止反向依赖**：`lib` 不许 import `components`；`store` 不许 import `pages`；主进程不许 import `src/`。

## 4. 关键文件影响面速查

| 文件 | 改动它会波及 |
|---|---|
| `src/types/models.ts` | 全部。改字段必须同步 `03`、`electron/store/*`、迁移函数、所有读取处 |
| `electron/parsers/html.ts` | EPUB + MOBI 两种格式、所有已有缓存需失效重建 |
| `electron/parsers/text.ts` | TXT 章节切分、`blockId` 稳定性、已有笔记定位 |
| `src/components/reader/Paragraph.tsx` | 标记视觉、高亮渲染、点击行为、笔记锚点 —— **最高危文件** |
| `src/store/useReader.ts` | 续读、进度、标记、面板状态 —— 阅读体验核心 |
| `src/styles/index.css` | 全部界面的观感 |
| `src/styles/reader.css` | 全部正文的观感 |
| `electron/store/userdata.ts` | 笔记与进度安全（写坏 = 用户数据丢失） |

## 5. 命名约定

| 类别 | 规则 | 例 |
|---|---|---|
| React 组件文件 | PascalCase.tsx | `BookCard.tsx` |
| 逻辑模块 | camelCase.ts | `anchor.ts` |
| 类型 | PascalCase | `ReadingSession` |
| 常量 | SCREAMING_SNAKE | `MAX_SEARCH_HITS` |
| CSS 变量 | `--kebab-case` | `--bg-reader` |
| IPC 通道 | `domain:action` | `note:save` |
| 数据目录 | kebab-case | `data/books/` |

## 6. 数据目录（运行时生成，不在仓库内）

```
%APPDATA%/moqi-reader/
├── data/
│   ├── library.json                 书库索引（BookMeta[]）
│   ├── settings.json                全局设置
│   ├── books/
│   │   └── {bookId}/
│   │       ├── book.json            规范化正文缓存（可删，会重建）
│   │       └── cover.jpg            封面（从书里抽出）
│   └── user/
│       ├── progress.json            { [bookId]: Progress }
│       ├── notes.json               { [bookId]: Note[] }
│       ├── sessions.json            ReadingSession[]（按天归档）
│       └── marks.json               （并入 progress.json，此文件预留）
└── logs/
    └── main.log                     仅记录错误
```

**可安全删除**：`books/`（缓存）。**绝不可删**：`user/`（用户笔记与进度）。
