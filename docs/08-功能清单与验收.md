## K. 数据备份与恢复（v0.4.0）

| 项 | 验收标准 |
|---|---|
| 导出 | 点「导出我的数据」→ 选目录 → 生成 `墨栖个人数据-日期/`，含三个 json + `导入说明.txt` |
| 导出内容正确 | 三个 json 与 `data/user/` 内对应文件内容一致 |
| 导入（标准） | 选中导出文件夹 → 提示「个人数据导入成功」，数字与源数据一致 |
| 导入（选上一层） | 选中 `data/` 或数据文件夹的父目录 → 仍能识别成功 |
| 导入（任意名） | 把文件夹改名成 `abc123` 再导入 → 仍成功（不依赖目录名） |
| 拒绝非本软件数据 | 选一个只有随机 txt 的文件夹 → 提示「不是『墨栖』需要的数据」，**现有数据零变化** |
| 拒绝空数据 | 选一个只有空 `{}` 的文件夹 → 提示「没有可导入的阅读数据」 |
| 不重复 | 同一份数据连续导入两次 → 笔记条数、会话条数不翻倍 |
| 合并优先新 | 导入一份 `updatedAt` 更早的 progress → 现有进度不被覆盖 |
| 自动备份 | 导入成功后 `data/user/_backup-*` 存在且含导入前的三个文件 |
| 不碰书籍 | 导入前后 `library.json`、`books/` 无变化 |
| 取消 | 系统对话框点取消 → 无报错、无写入 |

## 验收方法

| 类别 | 怎么验 |
|---|---|
| 功能 | 手动按清单逐条操作 |
| 视觉 | 截图后自检：留白 / 字号 / 对比度 / 有无硬编码色 |
| 性能 | DevTools Performance 面板录 10 秒滚动，看帧率与长任务 |
| 定位精度 | 改字号 → 改窗口 → 重启软件，三次后检查是否仍停在同一段 |
| 数据安全 | 阅读中 `taskkill /f` 杀进程，重开检查笔记与进度 |
