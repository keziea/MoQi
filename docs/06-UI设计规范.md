# 06 · UI 设计规范

> 这份文档定义墨栖的"长相"。**任何界面代码必须从这里取值，禁止自由发挥。**
> 统一入口：`src/styles/index.css` 中的 `:root` 变量。组件里出现硬编码色值 = 违规。

---

## 1. 气质定位

**三个词：纸感、克制、温润。**

- **纸感**：背景不是纯白，是纸的颜色；文字不是纯黑，是墨的颜色；分隔线不是灰，是纸的折痕。
- **克制**：全屏最多 2 个强调色块。按钮默认无边框、无阴影、无渐变。
- **温润**：所有颜色都偏暖（色相 20–40°），圆角柔和（8–20px），动效缓入缓出。

**反例（绝对不要）**：玻璃拟态、霓虹渐变、纯黑纯白高反差、大圆角糖果按钮、图标描边粗细不一、卡片套卡片。

## 2. 色彩系统

### 2.1 四套主题

阅读主题只影响**阅读区**，书架与面板始终跟随"纸白"。

#### 纸白（默认）

| Token | 值 | 用途 |
|---|---|---|
| `--bg` | `#F5F2EA` | 应用底色（暖纸） |
| `--bg-reader` | `#FAF7F0` | 阅读区（比应用底色更亮一档，聚焦） |
| `--surface` | `#FFFDF8` | 面板 / 卡片 / 浮层 |
| `--surface-sunken` | `#EFEBE1` | 内凹区域（输入框、进度槽） |
| `--text` | `#2B2620` | 正文墨色（对比度 13.2:1） |
| `--text-secondary` | `#6B6155` | 次要文字（对比度 6.1:1） |
| `--text-tertiary` | `#9A9082` | 提示 / 元信息（对比度 3.6:1，仅用于非正文） |
| `--line` | `#E6DFD1` | 极细分隔 |
| `--line-strong` | `#D5CBB8` | 明显边界 |
| `--accent` | `#9A6B3F` | 茶褐 · 主强调 |
| `--accent-hover` | `#835733` | 悬停 |
| `--accent-soft` | `rgba(154,107,63,0.10)` | 淡背景 |

`--bg: #E6EBE2` · `--bg-reader: #EDF1E9` · `--text: #293026` · `--accent: #5F7355`

#### 夜间（暖黑，不是纯黑）

| `--surface` | `#232019` |
| `--surface-sunken` | `#100E0C` |

| `--text-secondary` | `#9A9285` |

> 夜间模式的正文对比度控制在 9–11:1，**不要做到 15:1**——纯白字配纯黑底会产生光晕，久读刺眼。

### 2.2 高亮色（笔记）

| 名称 | 纸白下 | 夜间下 | 语义 |
|---|---|---|---|
| 陶土 `clay` | `rgba(196,124,92,0.26)` | `rgba(196,124,92,0.30)` | 重点 / 结论 |
| 苔绿 `moss` | `rgba(122,150,108,0.28)` | `rgba(122,150,108,0.30)` | 认同 / 共鸣 |
| 靛青 `indigo` | `rgba(106,126,166,0.24)` | `rgba(120,142,186,0.30)` | 疑问 / 待查 |
| 姜黄 `amber` | `rgba(206,166,86,0.30)` | `rgba(206,166,86,0.32)` | 金句 |

> 高亮用 `background` + `box-decoration-break: clone`，不做下划线、不做加粗，保持文字本身的呼吸。

### 2.3 语义色

`--danger: #B4543F`（删除、危险）· `--success: #5F7D5A`（保存成功）

### 2.4 阅读页「不模糊」红线

- 阅读页的顶栏、底栏、页码条一律**纯色不透明**，与阅读区同色（`--bg-reader`）。
- **禁止 `backdrop-filter`、半透明叠加、渐隐蒙版**。正文从栏下穿过时被模糊成脏痕，是本项目已明确废弃的错误。
- 翻页动画只允许透明度变化，**不允许位移/缩放**——位移动画会让整页文字在 160ms 内发虚。

## 3. 字体系统

### 3.1 字体栈

```css
--font-serif: "Source Han Serif SC", "Noto Serif SC", "Songti SC", "STSong", "SimSun", serif;
--font-sans:  "MiSans", "PingFang SC", "Microsoft YaHei", "Noto Sans SC", "Segoe UI", sans-serif;
--font-kai:   "KaiTi", "STKaiti", "Kaiti SC", "FangSong", serif;
--font-mono:  "Cascadia Mono", "Consolas", "SF Mono", monospace;
```

| 场景 | 字体 | 理由 |
|---|---|---|
| 正文阅读 | `serif`（默认） | 宋体有横向阅读的"字行感"，最接近纸书 |
| 界面 / 按钮 / 标题 | `sans` | 清晰、现代、小字号可读 |
| 可选「楷体」模式 | `kai` | 部分用户偏好手写感 |

> Windows 上 `SimSun` 在 19px 以上表现尚可；若用户装了思源宋体则优先命中。**界面字体绝不用宋体**——界面用宋体显旧。

### 3.2 字号与行高

界面侧（rem，基准 16px）：

| Token | px | 用途 |
|---|---|---|
| `--fs-2xs` | 11 | 徽标、极次要元信息 |
| `--fs-xs` | 12 | 元信息、快捷键提示 |
| `--fs-sm` | 13 | 次要按钮、标签 |
| `--fs-base` | 14 | 界面正文（默认） |
| `--fs-md` | 15 | 主要按钮、列表项 |
| `--fs-lg` | 17 | 卡片标题 |
| `--fs-xl` | 20 | 页面标题 |
| `--fs-2xl` | 26 | 书架主标题 |

阅读侧（用户可调，默认 19px）：

| 项 | 默认 | 可选范围 |
|---|---|---|
| 正文字号 | 19px | 16 / 18 / 19 / 21 / 23 / 26 / 30 |
| 行高 | 1.95 | 1.6 / 1.75 / 1.95 / 2.15 |
| 字间距 | 0.01em | 0 / 0.01 / 0.03 |
| 段间距 | 0.9em | 0.6 / 0.9 / 1.2 |
| 首行缩进 | 2em | 0 / 2em |
| 版心宽度 | 34em | 28 / 32 / 34 / 38 / 44 em |

**版心换算**：34em × 19px ≈ 646px。一行 33–34 个汉字，这是中文长文最舒适的密度（纸书通常 28–36 字）。

### 3.3 中文排版细节（必须有）

```css
.reader-body p {
  text-indent: 2em;            /* 首行缩进两格 */
  margin: 0 0 var(--para-gap);
  text-align: justify;          /* 两端对齐，行尾齐整 */
  text-justify: inter-ideograph;/* 中文标点挤压 */
  line-break: strict;           /* 避头尾处理 */
  overflow-wrap: break-word;
  hanging-punctuation: allow-end;
}
```

- 标点挤压：句号、逗号不占满格（`text-justify: inter-ideograph` 已处理大部分）
- 避头尾：句末标点不出现在行首
- **段落之间不加空行分割线**，靠段间距和缩进区分——这是纸书的做法

## 4. 间距刻度

只允许使用这组值（4 的倍数）：

`0 · 2 · 4 · 8 · 12 · 16 · 20 · 24 · 32 · 40 · 56 · 72 · 96`

> 字号与光学对齐允许 0.5px 级微调（如 9.5 / 13.5 / 17.5px）；布局间距仍以 4px 为主，避免节奏散掉。

常用语义：

| 场景 | 值 |
|---|---|
| 图标与文字 | 8 |
| 按钮内边距 | 10 × 16 |
| 卡片内边距 | 20 / 24 |
| 面板内边距 | 24 |
| 区块间距 | 32 |
| 页面顶部留白 | 56–72 |
| 阅读区上下留白 | 72（滚动）/ 上 28–44、下 54（分页） |

## 5. 圆角 / 描边 / 阴影

```css
--r-sm: 8px;    /* 小按钮、徽标 */
--r-md: 12px;   /* 按钮、输入框 */
--r-lg: 16px;   /* 卡片 */
--r-xl: 22px;   /* 大面板、抽屉 */
--r-full: 999px;

--shadow-xs: 0 1px 2px rgba(43,38,32,0.05);
--shadow-sm: 0 2px 8px rgba(43,38,32,0.06);
--shadow-md: 0 8px 28px rgba(43,38,32,0.09);
--shadow-lg: 0 20px 56px rgba(43,38,32,0.14);
```

**原则：**

- 书架卡片默认**无阴影**，只有 1px 边框；悬停时升到 `--shadow-sm`
- 抽屉/浮层用 `--shadow-lg`
- 阅读区**永不加阴影**
- 夜间主题下阴影改为 `rgba(0,0,0,0.5)`，并把强度降一档

## 6. 动效

```css
--ease-out: cubic-bezier(0.32, 0.72, 0, 1);   /* 主要曲线，收尾柔和 */
--ease-inout: cubic-bezier(0.65, 0, 0.35, 1);
--dur-fast: 120ms;
--dur-base: 200ms;
--dur-slow: 320ms;
```

| 交互 | 动效 |
|---|---|
| 按钮悬停 | 背景色 120ms |
| 抽屉开合 | 位移 + 透明度 320ms ease-out |
| 段落标记出现 | 左侧竖线 `scaleY(0→1)` 200ms + 背景淡入 240ms |
| 面板切换 | 淡入 180ms，位移 8px |
| 翻页（分页模式） | 整页 `opacity 0.72→1` 160ms；**不做位移**，避免文字发虚 |
| 书架卡片悬停 | `translateY(-3px)` + 阴影 200ms |
| 书籍打开 | 整页淡入 240ms，无缩放 |

**禁止**：弹跳（bounce）、旋转、超过 400ms 的动画、多元素依次延迟超过 80ms 的"瀑布"。

**必须支持** `@media (prefers-reduced-motion: reduce)` → 全部降为 0ms。

## 7. 组件规范

### 7.1 按钮

```
高度：36（常规）/ 44（主操作、老人友好）
圆角：--r-md
内边距：10 16
字重：500
字号：--fs-md

· 主按钮：bg = --accent，文字 #FFF，无阴影
· 次按钮：bg = transparent，1px --line，文字 --text-secondary，悬停 bg = --surface
· 幽灵按钮：无边框，仅图标，悬停 bg = --accent-soft
· 危险按钮：文字 --danger，悬停 bg = rgba(180,84,63,0.08)
```

图标按钮必须带 `aria-label` 与 tooltip（延迟 500ms 出现，样式极简）。

### 7.2 面板（抽屉）

- 宽度 360px（目录）/ 380px（笔记）/ 424px（数据，容纳 2×2 统计模板）
- 从右侧滑入，覆盖内容但**不遮顶栏**
- 面板背景 `--surface`，左侧 1px `--line`，无圆角（贴边）
- 标题栏：24px 内边距，`--fs-lg` 600 字重，右侧关闭按钮；可放一个轻量 `action`（如「写笔记」「展开 107 节」）
- 关闭方式：点 ×、按 Esc、点面板外区域

### 7.3 段落标记（"读到此处"）★ 核心视觉

```
┌─────────────────────────────────────┐
│ ▌▎ 他举起杯子，茶已经凉了。          │  ← 左侧 3px 茶褐竖线 + 顶部小书签
│                                     │
└─────────────────────────────────────┘
```

- 左侧竖线：宽 3px，高 100%，色 `--accent`，圆角 2px，距文字 18px
- 竖线顶端：12×16 的书签图标（实心 `--accent`），与段落首行基线对齐
- 段落背景：`--accent-soft`（10% 茶褐），左右各延伸 16px，圆角 6px
- 段落文字：不变色（保持可读性）
- 出现动效：竖线自上而下 200ms，背景 240ms 淡入
- 消失动效：反向 160ms

> **这是全项目最重要的一个视觉。** 用户要求"非常明显地出现一个标记"，但又要"好看不刺眼"。用"书签 + 竖线 + 极淡底"三重信号，既有存在感又不破坏阅读。

### 7.4 笔记高亮

```css
mark.hl { background: var(--hl-color); border-radius: 3px; padding: 1px 0; }
/* 有笔记内容的高亮，右下角一个 5px 小圆点标记 */
mark.hl.has-note::after { content:''; ... }
```

点高亮 → 弹出该笔记的浮层（可编辑 / 删除）。

### 7.5 输入框 / 文本域

`bg = --surface-sunken`，无边框（聚焦时 1px `--accent-line`），圆角 `--r-md`，内边距 12。
placeholder 用 `--text-tertiary`。

### 7.6 进度条

高 3px（阅读页底）/ 4px（书架卡片进度环线宽）。
槽 `--surface-sunken`，填充 `--accent`，圆角 full。
阅读页底栏：3px 可见条贴最底边，下面留 3px 独立命中区（不与翻页按钮抢点击），悬停加粗到 5px；**不使用百分比文字叠加在条上**。

### 7.7 空状态

居中，最大宽 320px。
一个 48px 线描图标（`--text-tertiary`）+ 一行标题（`--fs-lg`）+ 一行说明（`--fs-sm` `--text-secondary`）+ 一个主按钮。
文案要像人说话：「书架还是空的。把书拖进来吧。」

### 7.8 左侧导航栏

- 桌面（≥1180px）默认展开，宽 248px；覆盖在正文左侧留白上，**不改变版心与分页宽度**，因此不会因开合导致重新分页。
- 窄屏（<1180px）变为覆盖式抽屉（282px），默认关闭，用顶栏 `panel-left` 或 `Ctrl+\` 打开，带一层 `--scrim` 遮罩。
- 内容自上而下：品牌头（墨栖 / 我的阅读，左侧 3px 茶褐竖线）→ 书卡（封面 46×62 + 正在读 kicker + 书名/作者/进度）→ 计时卡（本次实时时钟、今天/本书今日、暂停/重置）→ 翻页/滚动切换 → 「阅读统计」入口（sparkles 图标 + 今日小结 · 统计模板）→ 目录树（只展开当前章）→ 最新笔记 + 写笔记/全部笔记。
- 背景为 `--bg-reader` 上叠一层极淡的 `--accent-tint` 渐变，右侧 1px `--line`；卡片使用 `--surface` + 1px `--line`，不投重阴影。时钟约 28px，是这一栏最大的字，但不能压过书名。
- 整栏 `overflow-y: auto`（`scrollbar-width: thin`），窗口高度不足时先滚动整栏，目录自身仍保留独立滚动；窄屏 282px 抽屉必须能滚到最底部的笔记入口。
- 计时控件：主按钮 32×32，播放/暂停同位置切换；重置是幽灵按钮，点一次进入确认态，2.8 秒未再点自动取消。**禁止一步清零。**

### 7.9 目录树

- 层级完全来自文件自带目录（EPUB 的 `toc.ncx` / nav），不按 `blockId` 猜层级，也不把原生三层压成两层。本书为 9 章 / 26 节 / 107 小节，共 142 条。
- 章行 13px/500，带折叠箭头与子项数；节行 12.5px/400，前置 3px 圆点；小节行 12px，缩进更深。
- 当前项：`--accent` 文字 + `--accent-soft` 底 + 左侧 2px 竖线；祖先章只做淡色标记。
- 打开目录只展开正在读的章；当前在「前言」这类没有子级的根时，改展开第一本有层级的章，保证一打开就能看见「章 → 节」。其余章折叠，避免几十行同时铺开。「展开 107 节」是显式展开，不是默认。
- 导航栏里的目录只显示章 + 节；完整目录在右侧抽屉，宽 360px。
- 完整目录顶部先给一张「正在读」摘要卡：kicker、当前节标题、百分比和 2px 进度条；下面是搜索框（占位「搜索目录」）。
- 搜索有结果时平铺命中项（最多 60 条），每行显示父级章、标题、原生层级标签；同一章内同名项只保留一条，并优先带 `blockId` 的更精确节点。
- 已读项：文字降到 `--text-tertiary`，圆点变 `--success`；当前项仍用 accent 高亮。子级用一条 1px `--line` 时间线收紧层级。

### 7.10 书架概览与书籍卡

- 书架视图嵌在工作台内，内容最大宽 1160px，左右留白随窗口增长；**不再有独立顶栏与书库概览卡**，这两部分由工作台顶栏和首页 hero 承担。
- 继续阅读大卡：封面 78×112、kicker「继续阅读」、书名/作者、格式 pill + 版本数 + 章节/字数；右侧百分比独立，底部 2px 轨道 + accent 细进度线表达进度，不在卡片中间横一根进度条。
- 工具栏：搜索框（320px）、筛选 chip、排序「最近/书名」；下方是网格，卡片宽 168–220px；末尾固定一张虚线「添加一本书」卡，高度与书籍卡同排，避免只有一本书时右侧像没做完。
- 书籍卡：外层不是整块 button，封面/标题/作者是一个 button，格式 pill 在其下方独立一行，避免嵌套按钮；当前格式 `--accent-soft` + accent 文字，其余为幽灵 pill；格式 pill 内边距 3×7、字号 9.5px，保证可读可点。百分比从格式行移到作者行右侧，格式行只留版本选择，避免一行挤五件事。同一本书的多个文件合并为一张卡，封面右上角显示「N 个版本」，格式 pill 取所有副本的并集。
- 卡片默认 1px `--line`、无阴影；悬停封面 `translateY(-3px)` + `--shadow-sm`，不改变网格尺寸。

### 7.11 工作台外壳

- 结构：左侧 96px 固定窄栏 + 右侧 64px 顶栏 + 独立滚动内容区；内容最大宽 1240px，左右内边距 40px，顶部 36px。
- 左栏：墨字方印（38×38，`--text` 底）+「墨栖 / 我的阅读」；5 个导航项（首页/书架/笔记/阅读统计/阅读记录），每项图标 20px + 12px 标签 + 9.5px 副标签；当前项 `--surface` 卡片 + 左侧 3px accent 竖线；底部主题/设置/版本。
- 顶栏：面包屑「我的阅读 / 当前分区」、右侧「本地 · 不联网」小圆点、数据目录按钮、导入按钮（tonal，不抢 hero 主按钮）；不使用毛玻璃。顶栏左右内边距与内容区同为 40px，面包屑与页面标题左缘对齐。

- 响应式：≤1180 左栏 88、顶栏/内容内边距 28；≤1000 指标 2×2、首页单列、画像统计横排；≤860 继续阅读卡改纵向；≤720 隐藏部分副标题。窗口高度 ≤760px 时左栏压缩（品牌 34px、隐藏副标签与版本号），保证 960×640 下 5 个导航和底部设置都可见。

## 10. 可访问性

| 项 | 要求 |
|---|---|
| 正文对比度 | ≥ 7:1（纸白 13.2:1 ✓，夜间 10.5:1 ✓） |
| 次要文字 | ≥ 4.5:1 |
| 可点击区 | ≥ 40×40px（图标按钮用 padding 撑开） |
| 焦点环 | 2px `--accent`，offset 2px，**不可去掉** |
| 缩放 | 200% 下不重叠、不截断 |
| 键盘 | 所有交互可 Tab 到达，Esc 关闭浮层 |
| 动效 | 尊重 `prefers-reduced-motion` |
| 屏幕阅读器 | 图标按钮必须有 `aria-label`，面板有 `role="dialog"` |
