# 00 · 项目总览

## 1. 这是什么

**墨栖**是一个 Windows 桌面中文阅读器。双击图标 → 看到书架 → 点一本书 → 开始读。
没有账号、没有广告、没有推荐、没有云同步。所有东西都留在你自己的电脑里。

名字取自「墨」与「栖」——墨是文字，栖是停留。**给文字一个可以久留的地方。**

---

## 2. 为谁而做

| 用户 | 特征 | 他最在意 |
|---|---|---|
| **主要用户**（本书的读者） | 40–75 岁，读中文长文（社科、纪实、文学），一次能读 30–120 分钟 | 字看得清、眼睛不累、下次打开能接着上次那行读、能划重点写想法 |
| **次要用户** | 不熟悉电脑操作的人 | 不要让我找菜单、不要让我记快捷键、不要弹窗吓我 |
| **隐含用户** | 未来接手这个项目的开发者 / AI | 结构清楚、文档完整、改一处不会崩三处 |

**设计时始终问自己：我妈（65 岁，会用微信，不会用 PS）能不能不看说明就用明白？**

---

## 3. 解决什么问题

现有阅读器的痛点，本项目的对策：

| 痛点 | 墨栖的做法 |
|---|---|
| 打开就忘上次读到哪 | 自动续读 + 可手动「读到此处」标记 + 一键回跳 |
| 不知道今天读了多久 | 无感计时，数据面板一页看清 |
| 划线做笔记很麻烦 | 拖选即出工具条，点段落即可整段记；4 种颜色 |
| 排版拥挤、眼睛累 | 版心窄（约 33 字/行）、行高 1.95、纸色背景、四套主题 |
| 一本书好几个格式不知道点哪个 | 自动归并为一本，优先选排版最好的那份 |
| 功能太多不敢点 | 主界面只有一个动作：打开书 |

## 4. 设计哲学（五条）

### 4.1 书是主角，软件是纸

界面不抢戏。没有渐变边框、没有玻璃拟态、没有动效炫技。
所有装饰都应该在**你不注意的时候消失**：顶栏滚动时淡出、侧栏不用时收起、进度条极细。

### 4.2 留白比装饰高级

版心宽度只占屏幕 50–60%，两侧大量留白。
留白不是浪费，是让眼睛有地方休息。**宁可少放一个按钮，也不要挤。**

### 4.3 一屏一件事

书架只干一件事：选书。
阅读页只干一件事：读。
笔记、数据、目录都是**抽屉**，用完即走，不常驻。

### 4.4 状态永远可见，但永远不吵

"你读到 37%"、"已读 12 分钟"——这些信息应该在，但要用最小的视觉重量表达（10–12px、低对比度、藏在角落）。

### 4.5 慢下来

翻页不要"唰"地飞过去，用 200ms 的柔和过渡；打开书不要闪白，用淡入。
阅读是慢活动，软件不该比人快。

## 5. 核心功能地图

```
墨栖
├── 书架
│   ├── 书籍卡片（封面 / 标题 / 进度环 / 格式徽标）
│   ├── 继续阅读（最近一本，大卡片）
│   ├── 导入书籍（拖拽 / 选择文件夹）
│   └── 书籍操作（删除记录、换格式、查看详情）
│
├── 阅读
│   ├── 正文（流式滚动 / 分页）
│   ├── 目录（多级折叠，当前章高亮）
│   ├── 读到此处标记（点段落即标记，视觉醒目）
│   ├── 续读（自动记住位置 + 一键回跳按钮）
│   ├── 笔记（选区批注 / 段落批注 / 4 色高亮 / 想法）
│   ├── 书签（手动，轻量）
│   ├── 搜索（全书，结果定位）
│   ├── 计时（本次 / 今日 / 累计）
│   ├── 数据面板（今日概览 / 近 7 天 / 这本书的进度 / 笔记统计）
│   └── 设置（字号 / 字体 / 行距 / 版心 / 主题 / 翻页方式）
│
└── 隐藏的用心
    ├── 窗口位置与大小记忆
    ├── 阅读时禁止系统休眠
    ├── 断电/崩溃后恢复阅读位置
    └── 笔记一键导出 Markdown
```

## 6. 不做什么（明确排除）

| 不做 | 原因 |
|---|---|
| 书城 / 在线书源 | 违反"绝不联网"铁律，且分散注意力 |
| 社交 / 评论 / 分享 | 阅读是私事 |
| AI 摘要 / 问答 | 会诱导用户不读原文；未来可作为独立插件，不进主线 |
| 阅读时长排行榜 / 连续打卡惩罚 | 制造焦虑，与"慢下来"冲突 |
| 复杂的书架分类 / 标签 / 评分 | 书少时是负担；用"最近在读"和搜索足够 |
| 移动端 / 网页版 | 本项目只服务 Windows 桌面 |

---

## 7. 成功的标准

做完之后，用这三条检验：

1. **母亲测试**：把电脑给一个 65 岁、只用过微信的人，不讲解，她能自己打开书、往下读、并且第二天还能接着读。
2. **两小时测试**：连续读两小时，眼睛不酸、没想找设置调字号、没被任何弹窗打断。
3. **半年测试**：半年后回来打开，笔记还在、进度还在、界面依然不觉得过时。
