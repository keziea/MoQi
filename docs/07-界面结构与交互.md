- 左栏 96px：品牌方印 + 5 个分区（首页/书架/笔记/阅读统计/阅读记录），当前项用 surface 卡片 + 左侧 accent 竖线；底部主题、设置、版本号。
- 顶栏 64px：面包屑「我的阅读 / 当前分区」；右侧本地标识、数据目录、导入书籍。无毛玻璃。顶栏左右内边距 40px，与内容区对齐。

- `Ctrl+O`、拖拽文件/文件夹仍全局可用；导入成功 Toast，不切页。

### 2.2 首页

- Hero：日期 eyebrow；两行衬线标题「下午好，/ 今天想读点什么？」；一行「书架上有 N 本书，M 本正在读」；主按钮「接着读《书名》」，次按钮「随便翻一本」。
- 今日目标卡：右上角下拉 15/30/45/60/90 分钟，右侧有 chevron 暗示可点；SVG 目标环显示今日完成百分比与今日累计，文字严格居中于环心；底部提示还差多久。目标只用于展示，不改变计时规则。
- 继续阅读卡：全宽，封面 78×112、书名/作者、格式/版本/章节/字数，右侧百分比独立 + 「翻开」；进度由卡片底边 2px 轨道 + accent 细线表达，不在卡片中间放进度条。
- 4 个指标：今天读了（含本周笔记数）、连续阅读（天数）、全部笔记（来自几本书）、正在读（共几本）。
- 最近 7 天：手写柱状图（高 158px），今天取 `max(历史, 实时)`；四条 25% 横向参考线；零值用中性短线；标题下有一句本周节奏说明，右侧本周累计；下方「看完整的阅读统计」。
- 最近笔记：最多 3 条，显示引文 + 书名/章节；右上是「全部」；底部一句「在阅读页选中文字，笔记会留在这里」。
- 书架一角：最多 5 本最近书 + 导入卡，固定 6 列，卡片最大 170px，列距 24px；书卡和导入卡同尺寸，封面下方只留标题与进度两行。1–2 本时引文「把一本书读旧，比把一百本书翻新更难。」放在右侧独立引用区，与书架之间隔 32px、左侧 1px 竖线、内容居中；≤860px 时改为书架下方的整行页脚。3 本以上不显示引文。

### 2.4 笔记

- 全库笔记按书分组；顶部统计「全部笔记 / 有笔记的书 / 最近 7 天」，右侧「复制全部笔记」；统计条右侧用衬线引号 `“` 收尾，不用小尺寸 quote 图标。
- 工具栏：搜索笔记、书名或章节；颜色筛选（全部/陶土/琥珀/苔绿/靛蓝）。
- 每条笔记卡显示引文、笔记（若有）、书名 · 章节、时间；点击整卡回到原文对应 block（`openTarget`）。
- 空状态：「还没有留下笔记。在阅读页选中一句话，或者点顶栏「写笔记」，就能记下来。」

### 2.5 阅读统计

- 分段控件：最近 7 / 30 / 56 天。
- 阅读画像：总时长、读书日、读书天占比、平均每天、最长连续；主文案「你读了 X」；标签「M 本书在架上」「N 条笔记」。
- 阅读趋势：14 天柱状图（按所选范围取最近 14 天），25% 参考线；右侧「读得最多的书」按书名合并副本时长排序，底部一条「按最近 N 天实际阅读时长统计」的说明收口，避免卡片下半部空着。
- 统计模板：阅读节奏 / 专注情况 / 读得最多的书 / 笔记习惯；选中后下方生成报告卡，支持「复制这段分析」。文案全部来自真实统计，不编造。
- 热力图：最近 36 周，方格 + 5 级色阶 + 月份标签；下方图例「少 → 多」。

### 2.6 阅读记录

- 统计：读过的天数、累计阅读、连续阅读、写过笔记的天数。
- 阅读日历：最近 52 周，按周一开头对齐；今天用实时 `max(历史, todaySeconds)`；空格子也有底色，不能出现横条。
- 时间线：最近 24 天有记录的日子，按日期倒序；同一天的多个副本按书名合并为一条 chip，不发生重复。
- 右上「看阅读统计」跳阅读统计分区。

**入口**：工作台顶栏，`打开数据文件夹` 图标左侧的 `import/export` 图标按钮。

## 3. 阅读页

### 3.0 两种阅读模式（默认分页）

用户要「一页内容刚刚好」，因此**默认分页模式**；滚动作为可选模式保留。

| 项 | 分页模式（默认） | 滚动模式 |
|---|---|---|
| 布局 | CSS 多列，横向翻页 | 纵向连续滚动 |
| 一屏 | 恰好一页，最后一行完整可见 | 连续，无页概念 |
| 翻页 | 滚轮 / ← → / PageUp·PageDown / Space / 底栏箭头 | 纵向滚动 |
| 页码 | `第 12 / 311 页` | 只有百分比 |
| 定位 | `blockId`（主）+ `pageIndex`（辅） | `blockId + delta` |

**顶栏与底栏必须完全不透明。** 早期版本用过毛玻璃（`backdrop-filter`），正文从下方穿过时被 blur 成一片脏痕——这是明确的设计错误，已彻底废弃。阅读页任何位置都**禁止 `backdrop-filter`**。

#### 分页版式与空白配比

```
┌──────────────────────────────────────────────────────────────┐
│ ←  负动产时代                        目录 笔记 写笔记 数据 🔍 Aa ☾ │ 52 纯色
├──────────────────────────────────────────────────────────────┤
│                    ↕ 上留白 28–44px（随窗口高度）              │
│      ┌────────────────────────────────────────────┐          │
│      │              第 1 章 标题                    │          │
│      │  正文……（版心 34em，一行约 33 字）           │          │
│      │  正文……                                      │          │
│      │  ……最后一行完整可见，绝不半行截断            │          │
│      └────────────────────────────────────────────┘          │
│   ← 页边留白 (视口−版心)/2 →│←  版心  →│←    页边留白          │
│                    ↕ 下留白 54px（给「回到标记」胶囊留位）      │
├──────────────────────────────────────────────────────────────┤
│ ◀  第 12 / 311 页  ▶   第2章 · 度假公寓启示录   6.7% · 今天 42 分钟 │ 44
├──────────────────────────────────────────────────────────────┤
│ ▓▓▓▓▓▓▓▓░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░ │ 3
└──────────────────────────────────────────────────────────────┘
```

| 位置 | 值 | 理由 |
|---|---|---|
| 左右页边距 | `(页宽 − 版心)/2`，最小 48px | 版心永远居中；窄窗自动收窄版心 |
| 上页边距 | `clamp(28px, 4.6vh, 44px)` | 少则压抑，多则一页装不下几行 |
| 下页边距 | 54px | 比上留白略大，纸书的呼吸感；同时容纳「回到标记」胶囊 |
| 版心宽 | `min(measure × fontSize, 页宽 − 96px)` | 34em × 19px ≈ 646px，约 33 字/行 |
| 段间距 | 0.8em | |

**分页算法（CSS 多列）**

- 页容器固定为一页大小（宽 = 页区宽，高 = 页区高），`overflow: hidden`。
- 正文容器 `column-width = 页宽`、`column-gap: 0`、`column-fill: auto`、`height: 100%`；内容自然向右溢出的每一列就是一页。
- 总页数 = `round(scrollWidth / 页宽)`；当前页 = `round(scrollLeft / 页宽)`。
- 翻页用 `scrollLeft` 瞬时定位（整数像素），**不用 transform 位移动画**——位移会让文字在动画期间发虚。
- 翻页只做 160ms 的 `opacity 0.72 → 1` 轻淡入，作为"换页了"的提示。

断裂规则：

```css
.chapter-block[data-level="1"] { break-before: column; } /* 只有一级章另起一页 */
.chapter-title, .blk-h2, .blk-h3, .blk-h4 { break-after: avoid; break-inside: avoid; }

```

> 这本书的 31 个 TOC 条目里只有 8 个是一级章，其余是节。**只让一级章另起一页**，否则 31 次断页会制造大量半空页。二级/三级节留在当前页，用一条 40px 细线 + 2.4em 留白分隔。

图片最大高度为页内容高度的 66%，保证图片与图注能落在同一页。

#### 翻页交互

| 方式 | 触发 |
|---|---|
| 滚轮 / 触控板 | 上下或左右滚动 = 前后翻页；累计 32px 触发一次，240ms 冷却 |
| 键盘 | `←` `→` `PageUp` `PageDown` `Space` |
| 底栏箭头 | 40×40，永远可见 |
| 首页 / 末页 | 对应箭头降到 0.28 并禁用 |

**点击正文不翻页**——那块区域留给「标记段落」，避免老人误触。

#### 页码与定位

```
当前页 = round(scrollLeft / 页宽)
总页数 = round(scrollWidth / 页宽)
当前锚点 = 页面左上区域 caretRangeFromPoint 命中的段落
         → 命不中时，取"起始页 ≤ 当前页"的最后一个段落

保存：blockId（主锚点）+ pageIndex（辅助）
恢复：以 blockId 所在页为准；找不到该段时退回 pageIndex；再不行按 ratio 定位
换字号 / 改窗口：先记住当前页顶部段落 → 重排 → 回到该段所在页
```

## 4. 页面切换

```
工作台（任意分区） ──点击书/笔记──► 阅读页     淡入 220ms，无位移
阅读页 ──返回工作台──► 工作台（离开前的分区）     淡出 180ms
```

- 「我的阅读」分区状态由 App 持有，阅读页卸载后不会重置到首页。
- 从笔记进入阅读页时带 `OpenTarget`，定位到该笔记的 chapterId/blockId，并做一次 600ms 呼吸提示。
- **返回工作台不弹确认。** 进度已实时保存，不需要"是否保存"这种吓人的东西。

## 5. 提示（Toast）

- 位置：底部居中，距底 88px
- 样式：`--text` 底 92% 不透明，白字，圆角 `--r-full`，内边距 10×18，`--fs-sm`
- 停留 2000ms，出现 180ms 上移淡入，消失 160ms
- 全局最多同时 1 条，新的替换旧的
- 文案示例：「已标记」「已保存」「已复制」「已导入《书名》」「已导出到 …」

**不用 Toast 报告错误** —— 错误用面板内联提示（带操作建议）。

## 6. 加载与空态

| 场景 | 表现 |
|---|---|
| 首次打开书（需解析） | 阅读区居中：一个 20px 环形进度 + 「正在打开…」；超过 5 秒显示「这本书比较大，再等一下」 |
| 解析失败 | 居中卡片：「这本书打不开」+ 原因（如"PDF 是扫描版，没有文字层"）+ 建议（"试试同书的 EPUB 版本"）+ 按钮「换一个版本」 |
| 书架为空 | 见 §2.7.4 |
| 搜索无结果 | 「没有找到「关键词」」+ 「换个词试试」 |
| 笔记为空 | 见 §3.9 |
| 数据为空 | 「还没有阅读记录。翻开一本书，这里就会有内容。」 |
