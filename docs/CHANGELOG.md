## 2026-11-10 · 修复分页模式下「进度显示 0%」

### 翻到最后一页，进度还是 0%

- **修复（根因）** 分页模式的进度按「当前锚点块之前的累计字数」算。但锚点可能落在**章节标题**上（`c3#title`），而字数索引只统计正文块（`c3#0`、`c3#1`…），查不到就返回 0，于是显示成 0%。现在查不到时按页码比例兜底：第 4 / 4 页显示 75%，不再显示 0%。
- **牵连** 只影响分页模式的进度百分比显示；滚动模式、阅读位置记忆、目录锚点均不受影响。

## 2026-11-10 · v0.3.0 书架「未读」彻底修好 / 未分类位置

### 书架永远显示「未读」的真正原因

- **修复（根因）** `BookCard` 的 props 里声明了 `status`，但**函数参数解构时漏掉了它**。于是组件里那个 `status` 实际读到的是浏览器全局的 `window.status`（一个空字符串），永远不等于 `'reading'`——所以不管书读到哪、标没标记读完，书卡都走到最后一个分支显示「未读」。现在把 `status` 正确解构出来。
- **加固** 书卡内部再做一层兜底：父组件万一没传 `status`，只要进度 `ratio > 0` 就按「在读」渲染，不会退回「未读」。

### 未分类的位置

- **修改** 「未分类」从分类行**末尾**移到「全部」后面第二个位置，并用虚线框与普通分类区分，一眼能认出「这是没有归类的书」，而不是一个奇怪的分类名。

## 2026-11-10 · v0.2.9 书架状态联动 / 分类弹窗重做

### 书架状态为什么不联动

- **修复（根因）** 书架从来没给书卡传过 `status`，只传了 `ratio`。书卡里 `status` 是 `undefined`，所以不管里面读到哪，外面永远按「未读」渲染。现在传了。
- **修复** 同一本书有多种格式副本时，阅读进度可能记在**副本 id** 上，而书架只查主 id。新增 `progressOf(group)`：主 id 没有就依次查所有副本，筛选计数、继续阅读卡、书卡状态、进度百分比统一走它。
- **修复** 首页「继续阅读」卡的进度同理，改为查主 id + 副本。

### 分类弹窗：定位和外观一起修

- **修复（根因）** 弹窗渲染在工作台的 `motion.div` 里，父级带 `transform`，`position: fixed` 会相对它定位——所以弹窗位置会偏、会「整体不对劲」。改用 `createPortal` 挂到 `document.body`。
- **重做** 外观：去掉左上角的大图标块和两行说明，改成「分类管理 + 一句副标题 + 右上关闭」的干净头部；列表行 44px，悬停才浮出「改名 / 删除」；底部新增区改成灰底条，输入框加回描边，颜色点与添加按钮同一行。
- **修改** 删除按钮的确认文案从「确认删除」缩为「确认？」，避免撑开行宽。

### 笔记导出弹窗

- **修复** 上一版只加了状态没渲染 JSX，「导出全部笔记」点了没反应。现在补成独立组件 `ExportNotesDialog`，同样用 Portal 挂到 body。

## 2026-11-10 · v0.2.4 导入修复 / 入口统一 / 项目瘦身

### 导入：单本书为什么一直进不来

- **修复（核心）** `scanForBooks` 只会遍历目录，把用户选中的**单个文件**也当成目录去 `readdirSync`，直接抛错跳过。所以「导入文件夹」能用、「导入书籍」永远没反应。现在文件走文件、目录走目录，两条路都能收。
- **修复** `library:import` 以前把文件路径也写进 `libraryDirs`（那是目录列表），导致扫描器每次都在一个"文件目录"上失败。现在只有真正的文件夹才进 `libraryDirs`，单文件只参与本次导入。
- **新增** 单次导入的文件会作为额外扫描路径并入本次扫描，不需要重启或手动刷新。
- **修复** 导入完成立刻回写 `books` 并提示「已导入 N 本书」，书马上出现在书架上；重复导入提示「这些书已经在书架上了」。
- **修复** 取消文件选择后不再自动弹第二个「选文件夹」对话框。

### 入口：只留一个名字，只留一个位置

- **修改** 顶栏的「导入书籍」按钮移除，导入入口只保留在书架里。
- **修改** 书架工具栏右侧：主按钮 **导入书籍**（选文件，可多选），右边一个小文件夹图标 = **导入整个文件夹**（文件夹里的多种格式会一起进来并自动归并成一本书）。
- **修改** 空书架状态：`导入书籍` + `导入文件夹` 两个按钮，不再是只有「选择书籍文件夹」。
- **统一** 全文案统一为「导入」，不再出现「添加书籍」。

### 清理

- **删除** 历次打包残留：`out-app2`（466MB）、`out-dir`、`out-final`、`out-final2`、`out-polish`、`out-release`、`out-release2`、`out-test`、`out-v2`、`out-v3b`、`release`、`dist-package`、`_empty`、`generated-images`、旧绿色版 `墨栖-v0.1.0` / `墨栖阅读器` / `墨栖阅读器-分页版`、`启动墨栖.bat`、`清理残留.bat`、`scripts/make-icon.js`（旧的逐像素图标脚本，误跑会覆盖现有图标）。
