# 墨栖 v0.7.0

> 发布日期：2026-11-21

## 这一版最值得说的

**装的时候两个位置一页定好；以后换数据位置，先留底、再校验、能回滚，旧目录还留 7 天。**

v0.6 已经把「程序 / 数据」分开、把数据目录扁平化。这一版补的是**不丢数据的最后一公里**：目标已有内容时不再只会拒绝，而是让你选择复用、覆盖（先备份）、重命名；迁移前自动留关键数据快照，复制完逐文件核对，失败自动回滚。

## 新增

- **同名目录四选一**：目标已有墨栖数据 → 复用 / 覆盖（先把旧目录改名备份）/ 重命名 / 取消。不是墨栖的目录只允许重命名或取消，绝不覆盖。
- **迁移前快照**：`backups\migration-<时间戳>\` 留 `library.json`、`settings.json`、`user/*.json` 和 `manifest.json`；书文件不重复打包，旧目录本身就是备份。
- **7 天保留期**：移动模式不再「下次启动就删」，旧目录保留 7 天；设置页可「立即清理」或「保留，不清理」。
- **上一位置回退**：写新指针前记录 `data-root.previous.txt`；新位置是空壳或打不开时，启动会回到真正有数据的位置。
- **崩溃恢复**：`migration.json` 记录迁移阶段；启动时清理临时目录、把已改名的旧目标恢复回去，不主动删数据。
- **安装器数据输入框**：默认就是 `%APPDATA%\MoQiData`，始终可编辑；点「浏览」选中后，`<上级>\MoQiData` 直接写回框内，不用再先勾「自定义」，也不在下面另起预览行。
- **程序 / 数据重叠拦截**：安装器与设置都会拒绝「数据在程序目录里」或反过来的情况。
- **导出物进数据域**：单本笔记导出默认落到 `MoQiData\exports\`；全部笔记导出对话框也默认指向这里。

## 改进

- 迁移校验从「文件数量」升级为「数量 + 每文件大小 + JSON 可解析 + 书数一致 + 关键 JSON sha256」。
- 加磁盘剩余空间预检；坏掉的 `library.json` 会直接中止迁移，原文件逐字节不变。
- 指针改为 `.tmp` + rename 原子写，断电/杀软拦截不再留下半截路径。
- 安全备份统一到 `backups\`；旧的 `_backups\` 在启动时一次性归并，两边都有内容时保留旧目录不硬合并。
- 便携版「改回默认」按 `<exeDir>\MoQiData` 走，不再错误地搬去 `%APPDATA%`。
- 设置页显示旧位置保留到哪一天，并给出「立即清理 / 保留」两个明确动作。
- 设置页的当前数据路径改为**框内只读输入**；点「浏览选择新位置」选完后，框内先显示最终目标，再弹确认，取消恢复原路径。

## 修复

- **安装器默认态点「浏览」不生效**：旧逻辑只看单选状态，选了文件夹也会被丢掉；现在输入框即真相。
- **目标已有非墨栖文件时静默失败**：以前点完确认没有任何提示；现在会明确告诉你目标已有内容并给出处理选项。
- **`MoqiProtectedCheck` 覆盖数据目录变量**：安装器受保护目录检查会顺手改掉 `$3`，后续「是否已有数据」可能判断错路径；改为只用 `$R` 寄存器。
- **空壳指针 / 空壳默认目录导致空书架**：数据其实还在旧位置，现在会先回退到有数据的位置，而不是默默新建空目录。
- **复制模式仍提示「下次启动清理」**：文案与行为不符，已改为「复制永久保留 / 移动保留 7 天」。
- **`backups` / `_backups` 双目录**：统一为 `backups`。

## 升级说明

- **直接覆盖安装即可**，不需要手动搬数据。已有数据位置（包括改到 D 盘 / 移动硬盘的位置）保持不变。
- 升级安装页只读汇总，不会移动数据、不会改指针；要换位置请装好后到「阅读设置 → 数据」或「数据备份与恢复 → 数据位置」。
- v0.5.x 的旧默认目录 `%APPDATA%\moqi-reader\data` 会在首次启动时并入 `%APPDATA%\MoQiData`；如果那里已经有一个空壳，会先清空壳再搬。
- 便携版默认数据仍在程序旁边的 `MoQiData`；只读 U 盘会自动退回系统目录。
- 卸载默认保留数据；勾选删除并二次确认才会删。
