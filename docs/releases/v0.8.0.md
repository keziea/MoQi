# 墨栖 v0.8.0

> 发布日期：2026-11-21
>
> 完整修复清单、测试输出与上传校验：[v0.8.0-verification.md](v0.8.0-verification.md)

## 这一版最值得说的

**只选一个安装位置，墨栖自己把 `Program` 和 `Data` 分好；书、笔记、备份全在 `Data` 里，整个文件夹搬到哪都能用。**

这不是换皮：程序、数据、绿色版压缩包和旧数据迁移都改成同一套“单根布局”。

## 新布局

```
D:\Apps\
└── MoQiReader\                ← 安装时自动创建，名字固定
    ├── Program\               ← 墨栖.exe、resources、locales
    └── Data\                  ← library.json、books、user、backups、exports、logs
```

- 你只选一个上级目录：`D:\` → `D:\MoQiReader`，`D:\Apps` → `D:\Apps\MoQiReader`。
- 如果选到的文件夹已经叫 `MoQiReader`，不再套一层。
- 数据位置由程序位置直接推导，不写注册表、不写 `%APPDATA%`、不写指针。
- 整个 `MoQiReader` 文件夹搬走/换盘，数据自动跟过去。
- 设置里不再提供“改数据目录”，只显示只读路径和「打开数据文件夹」。

## 新增

- **安装器单输入**：删掉第二个数据位置输入框，只选一次；框里直接显示最终 `MoQiReader` 目录。
- **绿色版同一布局**：压缩包根目录是 `MoQiReader`，里面自带 `Program` 和空的 `Data` 骨架；解压到哪就在哪工作。
- **旧数据自动迁移**：首次启动把 v0.7 的 `%APPDATA%\MoQiData` / 自定义位置 / 旧 `%APPDATA%\moqi-reader\data` 复制进新 `Data`，带进度小窗；旧数据不删，失败可重试。
- **书库自包含**：把 `Data` 外部的书复制进 `Data\books\{id}\source`；搬动文件夹后失效的绝对路径会按 `bookId` 自动找回内部文件。
- **`Data\runtime`**：Electron 的缓存、单实例锁也放进 `Data`，不再往 `%APPDATA%` 散。
- **容器根启动器**：`启动墨栖.cmd`，不想进 `Program` 找 exe 时双击它。
- **「我的数据」入口**：顶栏一个带文字的「我的数据」按钮；首页一张「我的数据」卡片，直接显示完整路径、打开文件夹、备份/恢复、导入/导出数据；阅读设置里也有「备份 / 恢复数据（导入导出）」。

## 改进

- 安装器自动创建 `Program` + `Data`，并在 `Data` 写 `.moqi-data` 标记。
- 升级只覆盖 `Program`，不会碰 `Data`；卸载默认保留 `Data`，勾选并二次确认才删。
- `Program Files` / Windows / 系统盘根一律拦截：数据要写在程序旁边，普通账户对受保护目录没有写权限。
- 绿色版解压到不可写位置会明确报错，不再偷偷退回 `%APPDATA%`。

## 修复

- v0.7 两个目录分散、迁移后数据可能落到旧位置的问题。
- 旧版 `data-root.txt` 指针在移动硬盘盘符变化后失效的问题（v0.8 不再依赖指针）。
- 书库绝对路径导致的“文件夹搬走书打不开”。
- 设置页还出现“浏览选择新位置”的旧交互。
- **删掉最后一本书后卡在「正在整理书库」**：空书架现在直接回到「书架还是空的 + 导入书籍」，导入按钮可点；还有书时删除不触发整理。

## 升级说明

- **直接覆盖安装即可。** 安装器会把新程序放到 `...\MoQiReader\Program`；旧版如果是 `...\MoQiReader\墨栖.exe`，旧根目录文件可安装后手动删除，数据不受影响。
- 首次启动会把旧数据复制进 `...\MoQiReader\Data`，原位置保留；迁移失败不会删旧数据，可重启重试。
- 旧版自定义数据位置（D 盘 / 移动硬盘）也能识别，只要旧指针还在。
- 旧版 `%APPDATA%\MoQiData` 不会立刻删除；确认新 Data 正常后，可自行清理。
