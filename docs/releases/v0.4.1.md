# 墨栖 v0.4.1

> 发布日期：2026-11-11

## 这一版最值得说的

**安装时终于能选装到哪了。** v0.4.0 的安装包是「一键安装」，直接把你塞进 C 盘一个很深的隐藏目录，既不能换盘，也找不到装哪去了。这一版改成标准安装向导 —— 可以选盘、选文件夹名。

## 修复

- **安装包不能选安装位置**：v0.4.0 用的是 electron-builder 的默认值 `oneClick: true`，会把程序直接装进 `C:\Users\<用户名>\AppData\Local\Programs\moqi-reader`。现在改成向导模式，安装过程中可以改路径，建议改成 `D:\Moqi` 这种一眼能看到的位置。
- 卸载依然只删程序，**不动你的阅读数据**（`%APPDATA%\moqi-reader`），进度、笔记、统计都还在。

## 改进

- 安装包文件名从 `墨栖 Setup 0.4.0.exe` 统一成 `Moqi-0.4.1-Setup.exe`，和 README 里的下载链接一字不差，不用再手工改名。
- 安装向导里可以选择是否创建桌面图标，装完可以选择立即运行。

## 升级说明

- **装过 v0.4.0 的话**：先卸载旧的 —— Windows「设置 → 应用 → 已安装的应用」里找到「墨栖 0.4.0」点卸载，或者直接运行安装目录里的 `Uninstall 墨栖.exe`。卸载不会删阅读数据。
- **只用绿色版的话**：把新的 7z 解压到你想要的目录即可，本来就由你决定放哪。
- 运行时代码这一版没有改动，只是安装方式变了。
