# 墨栖 v0.4.2

> 发布日期：2026-11-11

## 这一版最值得说的

**图标统一了。** 之前桌面图标是墨栖的标志，打开软件后窗口和任务栏却是 Electron 的默认图标。原因是打包时把「改写 exe 资源」关掉了，图标和产品信息根本没写进程序里。这一版修好 —— 桌面、窗口、任务栏、文件属性里看到的都是同一个墨栖图标和名字。

## 修复

- **桌面图标与程序图标不一致**：`signAndEditExecutable: false` 让 electron-builder 跳过了 rcedit，exe 的图标、产品名、公司名、版本号全部还是 Electron 的默认值。现在恢复默认行为，程序属性里显示「墨栖 / Moqi / 0.4.2」。
- 顺带修好了 exe 属性里「文件说明」一直显示 `Electron`、「原始文件名」显示 `electron.exe` 的问题。

## 升级说明

- 直接覆盖安装即可，书库和阅读数据都不受影响。
- **如果你之前把墨栖固定到过任务栏**：升级后可能需要取消固定、再重新固定一次，Windows 才会刷新图标缓存。
- 极少数情况下资源管理器图标不更新：重启电脑，或按 `Win + R` 输入 `ie4uinit.exe -show` 回车刷新缓存。
