# 墨栖 v0.4.0

> 发布日期：2026-11-11

## 这一版最值得说的

**阅读数据可以带走了。** 进度、笔记、阅读时长能一键导出成一个文件夹；换电脑或重装系统时导回来就行，不用再去翻 `%APPDATA%` 里那堆看不懂的文件。

## 新增

### 数据备份与恢复

工作台右上角新增「数据备份」按钮（数据文件夹图标左边那个）。

- **一键导出**：选一个位置，生成 `墨栖个人数据-日期/`，里面是三个数据文件加一份白话说明。说明文件直接写着「怎么恢复」，不用查文档。
- **一键导入**：选文件夹就行，**不挑名字**。叫 `墨栖个人数据-2026-11-11`、叫 `abc123`、甚至选它的上一层目录，都能认出来。
- **会挑数据**：只接受结构正确的内容。如果不是墨栖的数据，会明确告诉你「不是『墨栖』需要的数据」，并保持现有记录一个字不动。
- **只补不覆盖**：同一本书的进度按时间取新的，笔记按 id 去重。重复导入不会出现两份一样的笔记，也不会把新电脑上的记录冲掉。
- **自动备份**：导入前先把原数据复制到 `data/user/_backup-时间戳/`，万一导错了还能手动回滚。

## 改进

- 导入成功会告诉你「这次带进来多少、现在一共多少」，不用自己数。
- 失败会区分三种情况：不是本软件的数据 / 文件夹里没有数据 / 文件损坏读不出来，对应不同的处理建议。
- 面板里同时显示当前这台电脑上的数据量，导入前后能直接对比。

## 修复

- 修复 `npm run pack` 生成的 exe 版本信息被写死成 `0.1.6` 的问题，现在跟随 `package.json`。
- 修复 `npm run pack` 把绿色版输出到工作区顶层、污染项目目录的问题，现在输出到用户目录下的 `Moqi-portable`。

## 升级说明

- **直接覆盖安装即可**，书库、进度、笔记全部保留。
- 数据结构没有破坏性变更，不需要手动迁移。
- 老版本（v0.3.0 及更早）没有导出功能，升级后才有这个按钮。
