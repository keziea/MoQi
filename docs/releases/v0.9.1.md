# 墨栖 v0.9.1

> 发布日期：2026-11-27

## 这一版最值得说的

**版本终于看得见了。** 工作台右上角、左侧栏底部、阅读设置里都能看到当前版本；点开就是「关于墨栖」，一眼知道自己装的是不是最新版。

## 新增

- **关于墨栖**：显示版本、Electron / Chromium / Node、系统、数据目录；提供 GitHub / Gitee 发行版入口。
- **三个入口**：工作台右上角 `v0.9.1` 胶囊、左侧栏底部版本号、阅读设置底部「关于墨栖 · v0.9.1」。
- **复制版本信息**：一键复制「墨栖 v0.9.1 + 运行环境 + 系统 + 数据目录」，反馈问题时直接贴。
- **发版自检**：`npm run check:version` 检查 package / README / AGENTS / CHANGELOG / 发布说明 / 四个下载链接；`npm run dist` 前自动跑，不通过不许打包。

## 修复

- 删除旧版工作台侧栏写死的 `v0.4`。现在所有版本号只来自 `package.json`，每次发版自动变。
- 统一版本可见位置，避免“设置里是 v0.8.0、侧栏是 v0.4”这种对不上的情况。

## 说明

- 安装方式、数据目录、备份恢复与 v0.9.0 完全一致；升级只覆盖 `Program`，`Data` 里的书、笔记、进度、生字本都会保留。
- 软件是离线的，不会自动联网检查更新；关于面板里的「GitHub / Gitee 发行版」按钮会打开对应页面，自己对比版本即可。
- 版本管理规则写在 `docs/12-版本管理与发布清单.md`：哪些必须改、哪些不许动、什么时候升版本、什么时候不升。

## 验证

- `npm test`：117 + 29 + 14 项全部通过（含新的版本一致性检查）。
- 工作台右上角、侧栏、设置、关于面板四处版本号一致。
- 关于面板在纸白 / 夜间主题下可读；`Esc`、点遮罩都能关闭。
