# 墨栖 v0.6.0

> 发布日期：2026-11-21

## 这一版最值得说的

**目录名字一眼就懂，数据不再藏两层，装的时候一页看全。**

程序、配置、数据各有各的固定名字，不再互相套娃；安装向导把「程序装哪」和「数据放哪」放在同一页，各自有实时预览。

## 新增

- **三个名字分清**：程序目录 `MoQiReader`、配置目录 `moqi-reader`（只放位置记录与启动日志）、数据目录 `MoQiData`。改名字只需改 `package.json → moqi` 一处。
- **数据目录扁平化**：`MoQiData\` 里直接放 `library.json`、`books\`、`user\`、`backups\`、`logs\`，去掉原来 `MoQiData\data\` 的重复一层。
- **安装器同页双路径**：一页同时显示「① 程序安装目录」「② 用户数据目录」，各自带「浏览…」与实时预览；底部写明「卸载默认保留数据」。
- **程序目录不再套娃**：选 `D:\` 才自动建 `D:\MoQiReader`；选 `D:\Apps` 就直接用 `D:\Apps`，不再变成 `D:\Apps\MoQiReader`。选到非空文件夹会提示。
- **升级只读汇总**：已经装过或已有数据时，这一页只展示当前程序与数据位置，不改动、不搬家。
- **旧数据兼容**：v0.5.x 的 `MoQiData\data` 布局会自动认出来继续用；系统默认目录会在首次启动时搬到新的 `MoQiData`，书、笔记、进度一样都不会少。

## 改进

- 数据指针 `data-root.txt` 现在直接指向数据目录本身，语义与运行时解析一致。
- 数据目录标记 `.moqi-data` 升级为 `layout: flat / version: 2`，卸载与迁移都能据此认目录。
- 卸载删数据同时兼容新旧两种布局；仍然默认保留、勾选 + 二次确认才删。
- 阅读设置「数据」里的说明改为「书架、笔记、书文件都直接放在里面」。

## 修复

- 对齐了路径服务、迁移逻辑、安装器与测试对数据布局的理解，避免迁移后数据落到 `MoQiData\data` 而软件去读 `MoQiData\` 的不一致。
- 安装器创建数据目录失败时不再写指针；保留数据时不再误删指针。

## 升级说明

- **直接覆盖安装即可，不需要手动搬家。** 已有数据位置（包括你改到 D 盘 / 移动硬盘的位置）保持不变。
- 系统默认位置的旧数据会在首次启动时自动搬到 `%APPDATA%\MoQiData`；如果因为权限没搬成，会继续用原目录，功能不受影响。
- 便携版（解压版）默认数据仍在程序旁边的 `MoQiData`；只读 U 盘会自动退回系统目录。
- 卸载默认保留数据。
