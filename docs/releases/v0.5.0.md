# 墨栖 v0.5.0

> 发布日期：2026-11-20

## 这一版最值得说的

**换电脑终于不用折腾了。** 现在导出就是一个完整 ZIP：书架、分类、笔记、读到哪、阅读时长、封面和书文件全在里面；新电脑上用「导入压缩包」或「导入文件夹」一步恢复。

数据放在哪也交给你决定：安装时能选，装好之后也能随时改。选一个目录，墨栖会在里面建一个 `MoQiReader` 文件夹，数据放在 `MoQiReader\data`。

## 新增

- **完整备份（ZIP）**：导出内容从「三个 JSON」升级为整份数据 —— `library.json`（书架与分类）、`settings.json`（笔记分类颜色、每日目标）、`user/`（进度 / 笔记 / 阅读时长）、`books/{id}/`（封面与原书文件）。另附 `manifest.json` 与给普通人看的 `导入说明.txt`。
- **两种恢复方式**：「导入压缩包」直接选 `.zip`，不用先解压；「导入文件夹」选解压后的目录，外面多套一层也认。旧版「三个 JSON」的备份照样能导入。
- **数据位置可选**：安装器在「选择安装位置」之后新增一页「选择数据存放位置」，默认「文档」，带浏览按钮，页面上直接写明将创建的 `MoQiReader` 与 `MoQiReader\data`。应用内也能改：工作台 →「数据备份与恢复」→「数据位置」。
- **迁移有进度、可回退**：复制 → 核对文件数量 → 切换 → 自动重启；旧位置在下次启动时清理；中途失败原数据一个字节都不动。
- **位置不可用自动回退**：移动硬盘没插时退回默认位置，面板上红字提示原路径；插回后重启自动回去。

## 改进

- 备份面板重做：数据概览（书架 / 笔记 / 天数 / 体积 + 上次备份时间）、「连书一起打包」开关、分阶段进度条、结果卡片。
- 恢复前自动留底：`data/_backups/<时间戳>/`，附一份白话 `说明.txt`。
- 分类、笔记分类颜色、每日目标随备份走；主题、字号、窗口位置仍跟机器走。
- 备份包不塞解析缓存（`book.json`），体积更小；恢复后首次打开自动重建。
- 恢复成功后，工作台的书架、笔记、进度、统计一起刷新。
- 安装器升级时自动跳过「数据位置」页，不会把已经改到 D 盘的位置指回默认。
- 测试从 0 扩到 51 项：导出 / 恢复 / 重复导入幂等 / 嵌套文件夹 / 旧版兼容 / 轻量备份 / 坏包 / 迁移 / 冲突 / 回退。

## 修复

- **换电脑后进度和笔记对不上**：书 ID 由「书所在文件夹 + 书名」生成，路径一变 ID 就变，进度和笔记全部错位。现在书文件会复制进墨栖自己的数据目录，并沿用原 ID。
- **旧版导出丢书架**：原来只复制 `data/user/` 下三个 JSON，书架、分类、封面、书文件都不在包里，恢复后书架是空的。
- **换数据位置后书打不开**：`library.json` 里存的是绝对路径，搬家后没跟着改，旧目录一删就失效。现在会改写路径，并把放在外部的书复制进新的数据目录，新位置真正自带书。
- **恢复入口不明确**：原来的「压缩包 / 文件夹」两个小按钮改成「以压缩包形式导入」「以文件夹形式导入」两条整行入口，各带一句说明。
- **版本索引漏了 v0.4.2**：`docs/releases/README.md` 已补。
- **7z / rar 报错难懂**：现在直接提示「先解压成文件夹，或用 ZIP 重新打包」。

## 升级说明

- 直接覆盖安装即可。0.4.x 的书库、笔记、进度会被直接读取，不需要迁移。
- 默认数据位置不变（`%APPDATA%\moqi-reader\data`）；只有你主动改位置才会搬。
- 迁移过程中应用会自动重启一次，属正常现象。
- 安装包已发布，校验值见下表。
