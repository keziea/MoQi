# 墨栖 v0.9.0

> 发布日期：2026-11-27

## 这一版最值得说的

**遇到不认识的字，点一下就能看拼音、释义和组词——不用离开这一页，也不用跟会跑的按钮捉迷藏。**

## 新增

- **点字查字典**：单击段落 → 页边操作坞点「查字」→ 点段落里任意一个汉字，弹出字词卡：拼音（多音字全部列出）、部首、笔画、分条释义、组词。
- **划词查词**：选中 2–8 个字 → 工具条「查词」→ 整词拼音 + 释义；有多个读音的字会逐字列出，不猜读音。
- **生字本**：字词卡「收进生字本」，随「我的数据」一起备份；卡内可看列表、重查、移除。
- **朗读**：字词卡「朗读」调用系统中文语音（没有中文语音时静默降级）。
- **离线字词库**：内置 16141 个单字、25000 条词语，4.31MB，第一次查字时才加载；不联网、不上传查询。

## 改进

- **段落菜单改为固定操作坞**：原来的菜单会按点击点在段落上方/下方之间翻转。现在固定在正文栏右侧页边、阅读区垂直居中，三个动作永远是「查字 / 读到这 / 写笔记」；右侧放不下自动换左侧，再不行退到底部横条。**不压正文**。
- **查字态**：当前段落变暖、鼠标变 help；字外框是 1.5px 描边 + 外晕，不填充、不盖字；点段落外或 `Esc` 才退出。
- **字词卡位置**：优先正文栏外侧页边，和被查段落同一水平线；窗口窄时放在字的另一侧，尽量不压正在看的那一段。
- 工作台侧栏版本号改为读取程序版本，不再硬编码。

## 说明

- 安装方式、数据目录、备份恢复与 v0.8.0 完全一致；升级只覆盖 `Program`，`Data` 里的书、笔记、进度、生字本都会保留。
- 字词库中《现代汉语词典》正文版权归商务印书馆所有，当前仅供个人学习使用；商业发行需自行取得授权或替换词库。详见 `src/assets/dict/README.md`。
