# 墨栖 v0.5.1

> 发布日期：2026-11-21

## 这一版最值得说的

**装的时候就能看清楚：程序装在哪、数据放哪。** 程序目录固定为 `moqi-reader`，数据目录固定为 `MoQiData`，两者互不绑定。装好之后，设置里还能把数据「复制」或「移动」到别的盘。

## 新增

- **安装器程序页**：只选一个根目录，实时预览 `根\moqi-reader`；目录已存在会提示「继续会更新程序文件，用户数据不受影响」。
- **安装器数据页**：默认系统位置，也可以选别的盘；自动创建 `MoQiData`，这一层名字只读、不能改；实时显示 `将创建` / `数据目录` 两行。
- **受保护目录拦截**：Program Files、Windows、系统盘根一律阻断，并说明「会被 Windows 虚拟化重定向」。
- **设置里复制 / 移动两种迁移**：确认框三选一——复制（保留旧数据）、移动（下次启动删旧目录）、取消。
- **便携包默认数据在程序旁边**：`<解压目录>\MoQiData\data`；只读 U 盘自动退回系统目录；老用户数据还在 `%APPDATA%` 时先沿用，并在设置里提示可搬。
- **卸载可选删除数据**：默认不删；勾选后二次确认；只删带 `.moqi-data` 标记的数据根，保留数据时指针也保留，重装还能找回原位置。
- **固定英文名集中生成**：`package.json → moqi` 一处改，`scripts/gen-names.js` 同时生成 NSIS define 和 TS 常量，安装器与代码不再硬编码。

## 改进

- 数据目录名从 `MoQiReader` 改为 `MoQiData`，一眼能看出是数据。
- 安装器数据页遇到已有数据只做汇总，不覆盖、不移动。
- 升级安装按 `$INSTDIR\墨栖.exe` 是否存在自动跳过程序页，沿用旧路径。
- 数据目录创建失败会当场阻断，不再写一个指向不存在路径的指针。

## 修复

- 程序目录不会重复拼接成 `moqi-reader\moqi-reader`。
- 目标数据目录已有非墨栖文件时拒绝复用，避免误覆盖。
- 迁移复制不完整 / 写指针失败时删除本次产物，原数据一个字节不动。
- 卸载时保留数据则保留指针，重装不会丢自定义位置。

## 升级说明

- 覆盖安装即可；已有数据位置不变（指针优先），0.5.0 搬过家的用户仍指向原目录。
- 只有新建位置才会使用 `MoQiData`。
- 便携版老用户的数据仍在 `%APPDATA%`，设置里会提示可搬到程序旁边。
- 卸载默认保留数据。
