## 1. 这一版解决的 bug

### 1.1 删掉最后一本书后卡在「正在整理书库」

**现象**

书架里只有一本书时，从「更多操作 → 从书架移除」删掉它，界面进入「正在整理你的书库」，一直不结束；空书架没有「导入书籍」按钮，无法继续导书。还有书时删除则正常。

**根因**

`src/store/useLibrary.ts` 的 `load()` 里有一段旧逻辑：

```ts
if (books.length === 0) {
  set({ scanning: true });
  const scanned = await ipc.library.scan({ silent: false });
  ...
}
```

书架为空时它会自动扫描。扫描失败或没有正常结束时，`scanning` 一直保持 `true`；而 `EmptyShelf` 只有在 `!scanning` 时才显示「导入书籍」，于是界面永久停在「正在整理」。

**修复**

- `load()` 只读取现有书库，不再因为 0 本自动扫描。
- `load()` / `remove()` / `scan()` 的所有结束与异常路径都复位 `scanning` 和 `scanProgress`。
- 删到 0 本时同时清空搜索词、状态筛选、分类筛选，直接回到初始空书架。
- 还有书时删除只更新列表，不触发扫描、不重置其他书状态。

**验证**

打包版真实 UI 测试，不是只看代码：

```text
✓ 应用已启动
✓ 已进入书架页面
✓ 书架显示《最后一本书》
✓ 删除后回到空书架
  contains 导入书籍 = true
  contains 正在整理 = false
  contains 最后一本书 = false
  导入按钮 = {"found":true,"disabled":false}

UI 测试通过
```

脚本：`scripts/test-ui-empty-shelf.js`；命令：`npm run test:ui`。

### 1.2 「导入 / 导出」入口太隐蔽，用户不知道是干什么的

**现象**

顶栏只有两个无文字的图标按钮（一个像导入箭头，一个文件夹），用户不知道哪个是数据备份/恢复，也不知道点开后能干什么。

**修复**

- 顶栏改为带文字的 **「我的数据」** 按钮。
- 首页新增 **「我的数据」卡片**：
  - 标题「我的数据」，小标「数据文件」；
  - 完整只读路径；
  - 「打开文件夹」；
  - 「备份 / 恢复」；
  - 「导入 / 导出数据」；
  - 「导入书籍」。
- 阅读设置 → 数据 → 新增 **「备份 / 恢复数据（导入导出）」**。
- 弹窗标题改为 **「我的数据」**，顶部一句说明「这里可以做什么」，区块标题改为「导出数据 / 导入数据」。

涉及：`src/pages/Workspace.tsx`、`src/components/workspace/WorkspaceOverview.tsx`、`src/components/workspace/DataBackup.tsx`、`src/components/reader/SettingsPanel.tsx`。

### 1.3 数据位置分散、换电脑/搬文件夹后书打不开

**修复**

- 统一单根布局：

```text
<父目录>\
└── MoQiReader\
    ├── Program\   程序
    └── Data\      全部用户数据
```

- 数据位置由 exe 位置相对推导，不再依赖 `data-root.txt`、`%APPDATA%` 或盘符。
- 整个 `MoQiReader` 文件夹搬走/换盘后，Data 自动跟着走。
- 旧 v0.7 数据首次启动复制进新 `Data`：旧数据不删、失败可重试、`library.json` 路径改写。
- `Data` 外部的书复制进 `Data\books\{id}\source`，原文件不删；移动后失效的绝对路径按 `bookId` 自动找回。
- 设置里不再允许改数据位置，只显示只读路径和「打开数据文件夹」。

### 1.4 安装器两个输入框、数据路径容易选错

**修复**

- 安装器只保留一个「安装位置」输入。
- 选 `D:\` → `D:\MoQiReader`；选 `D:\Apps` → `D:\Apps\MoQiReader`；已经是 `MoQiReader` 不再套一层。
- 自动创建 `Program` + `Data`；`$INSTDIR` 固定为 `...\MoQiReader\Program`。
- `Program Files` / `Windows` / 系统盘根阻断。
- 升级只覆盖 `Program`；卸载默认保留 `Data`。

### 1.5 绿色版把真实数据带进压缩包 / 解压后找不到 Data

**修复**

- 压缩包根目录固定 `MoQiReader`。
- 自带 `Program` + 空 `Data` 骨架（只有目录和 `.moqi-data`）。
- 发布包 `Data` 里没有 `library.json`、没有书、没有 `runtime`。
- 解压到哪就在哪工作；`启动墨栖.cmd` 可直接双击。

## 5. 已知限制 / 还需要人工确认的

1. **安装向导的完整鼠标点击流程**没有在真实用户注册表/AppData 上跑过；已做 NSIS 编译、安装器路径函数 14 项测试、绿色版启动冒烟。建议在测试机从 v0.7 覆盖安装一次，确认旧数据迁移和快捷方式。
2. 安装包未签名，Windows SmartScreen 首次运行仍会提示“未知发布者”。
3. 安装包只放在 Release，不进 Git 历史；如果希望 `release/` 目录也提交 v0.8.0 二进制，需要额外处理仓库体积（约 +150 MB）。
4. Gitee 源码通过批量 API 分 6 个提交上传，提交历史比 GitHub 多；最终文件内容与 GitHub 一致。
