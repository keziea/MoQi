# 墨栖 v0.3.0

> 发布日期：2026-11-10
> 说明：这是本项目第一个公开版本。当时还没有单独存档发布说明，以下内容依据 `docs/CHANGELOG.md` 回溯整理。

## 这一版最值得说的

第一个可以拿给别人用的版本：四种格式、纸书排版、自动续读、划词笔记、阅读统计，所有数据只存在本机。

## 新增

- **书籍解析**：EPUB / MOBI / PDF / TXT 四种格式；同一本书的多个格式自动合并成一张卡
- **阅读引擎**：分页与滚动两种模式；自动记住读到哪，关掉再开回到同一段
- **「读到此处」标记**：单击段落生成标记，底栏可一键回到标记位置
- **划词笔记**：四色高亮、跨段选择、整段笔记、按颜色筛选、一键导出 Markdown
- **阅读统计**：今日目标环、连续阅读天数、52 周热力图、按书明细、四种可直接复制的统计模板
- **四套主题**：纸白 / 米黄 / 护眼绿 / 夜间；字号 14–32、行距 4 档、字体宋黑楷、版心 5 档
- **完全本地**：不联网、不需要账号，书和笔记只存在自己电脑里

## 修复

- 修复分页模式下「翻到最后一页，进度仍显示 0%」：锚点落在章节标题块上时查不到累计字数，改为按页码比例兜底

## 升级说明

- 首次安装直接使用
- 从更早的内部版本升级也无需手动迁移，数据结构没有破坏性变更
